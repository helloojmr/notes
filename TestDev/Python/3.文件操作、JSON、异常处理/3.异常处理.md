## try-catch
### 基本语法
```
try:

except 异常类型1:

except 异常类型2:

except Except as e:

else:未发生异常时执行
finnaly:无论是否异常都要执行

```
### 完整示例

```
try:
    # 可能引发异常的代码
    result = 10 / 0
except ZeroDivisionError as e:
    # 捕获特定异常
    print(f"除零错误: {e}")
except (ValueError, TypeError) as e:
    # 捕获多个异常
    print(f"类型错误: {e}")
except Exception as e:
    # 捕获所有其他异常（基类）
    print(f"未知错误: {e}")
else:
    # 没有异常时执行
    print("一切正常")
finally:
    # 无论是否异常都执行
    print("清理资源")
```

## 常见异常类型

- **`FileNotFoundError`**：文件不存在
- **`PermissionError`**：权限不足
- **`json.JSONDecodeError`**：JSON解析失败
- **`requests.exceptions.Timeout`**：请求超时
- **`requests.exceptions.ConnectionError`**：网络连接失败
- **`AssertionError`**：断言失败
- **`KeyError`**：字典键不存在
- **`IndexError`**：列表索引越界
- **`TypeError`**：类型错误
- **`ValueError`**：值错误


## 异常的传递
- 异常会沿着函数调用栈向上传递，直到被捕获。
- 如果一直未被捕获，程序终止。
## 抛出异常
### 使用方式
- 在测试中，可以用 `raise` 主动抛出异常，例如验证失败时。
### 示例代码
```
def check_response(response):
    if response.status_code != 200:
        raise ValueError(f"状态码错误: {response.status_code}")
    return True

# 调用
try:
    check_response(resp)
except ValueError as e:
    print(f"测试失败: {e}")
```
### 自定义异常

#### 示例代码
```
class TestAssertionError(Exception):
    """测试断言失败异常"""
    pass

def assert_equal(actual, expected):
    if actual != expected:
        raise TestAssertionError(f"期望 {expected}, 实际 {actual}")
```
## 重试机制
```
import time
import requests

def request_with_retry(url, max_retries=3, delay=1):
    for i in range(max_retries):
        try:
            response = requests.get(url, timeout=5)
            response.raise_for_status()  # 状态码非200时抛出异常
            return response
        except (requests.exceptions.Timeout, 
                requests.exceptions.ConnectionError) as e:
            print(f"第{i+1}次尝试失败: {e}")
            if i == max_retries - 1:
                raise  # 最后一次仍失败，抛出异常
            time.sleep(delay)
        except requests.exceptions.HTTPError as e:
            print(f"HTTP错误: {e}")
            raise  # 直接失败，不重试

# 使用
try:
    resp = request_with_retry("https://api.example.com")
    print("请求成功")
except Exception as e:
    print(f"最终失败: {e}")
```

## 异常处理最佳实践
### 核心原则
- **精确捕获**：尽量捕获具体异常，避免使用 `except Exception` 掩盖真正的问题。
- **不要吞异常**：除非有明确目的，否则不要写 `except: pass`。
- **记录日志**：在 except 块中用 `logging` 记录异常信息。
- **finally 释放资源**：文件、数据库连接等在 finally 中关闭。
### 示例代码
```
import logging

logging.basicConfig(level=logging.INFO)

try:
    with open('test.txt') as f:
        content = f.read()
except FileNotFoundError:
    logging.error("文件不存在")
except Exception as e:
    logging.exception("未知错误")  # 自动记录堆栈
```

## 什么是JSON
### 核心概念
- 基于文本，独立于语言的轻量级数据交换格式，本质是一个字符串。`[],{}`
- **json对象**:`{"key":value}`必须用大括号，必须有键值对
- **json数组**:`[[],[]]`数组嵌套数组，也是合法的json格式

## JSON数据类型与Python对照

- **object**：dict
- **array**：list
- **string**：str
- **number (int)**：int
- **number (float)**：float
- **true**：True
- **false**：False
- **null**：None

## 格式规范
- key必须是字符串，必须用**双引号**，不能用单引号。
- value可以是数字、字符串（必须用双引号）、布尔值、数组、对象、null(python中是None)
- 不能有注释。
- 后一个成员后面不能有逗号。

## JSON模块核心方法
### 方法详解
- **`json.dumps(obj)`**
  - 作用：Python对象 → JSON字符串
  - 返回值：str
- **`json.loads(s)`**
  - 作用：JSON字符串 → Python对象
  - 返回值：dict/list等
- **`json.dump(obj, file)`**
  - 作用：Python对象 → JSON文件
  - 返回值：无
- **`json.load(file)`**
  - 作用：JSON文件 → Python对象
  - 返回值：dict/list等


### dumps与loads示例
```
import json  
  
# Python dict  
dict_obj = {  
	"name": "Alice",  
	"age": 25,  
	"is_student": False,  # Python的False  
	"hobbies": ["reading", "hiking"],  
	"metadata": None  # Python的None  
}  
  
# 转换为JSON字符串  
json_str = json.dumps(dict_obj) #列表或字典 
print(json_str)    
# 输出：{"name": "Alice", "age": 25, "is_student": false, "hobbies": ["reading", "hiking"], "metadata": null}  
# 注意：False → false，None → null，字符串变双引号  
  
# 从JSON字符串转回dict  
new_dict = json.loads(json_str)  
print(type(new_dict))  # <class 'dict'>
```
### 读取文件
- 读取文件
### 读取文件示例
```
import json
json.loads('./test.json')  # ❌ 错误！json.loads()期望接收 JSON 格式的字符串

import json

# 方式1：两步法（先读文件，再解析）
with open('./test.json', 'r', encoding='utf-8') as f:
    json_string = f.read()  # 读取文件内容为字符串
    data = json.loads(json_string)  # 解析JSON字符串

print(data)

# 方式2：一步法（直接加载文件）
with open('./test.json', 'r', encoding='utf-8') as f:
    data = json.load(f)  # 直接加载文件对象

print(data)

----------------
import json
with open('./test.json',encoding='utf-8') as f:
    json_str=f.read()      # 第一次读取：读取所有内容
    json.loads(json_str)   # 第一次解析：使用读取的内容
```

### 写入文件
- 写入文件
### 写入文件示例
```
import json

# Python对象
data = {
    "name": "张三",
    "age": 25,
    "is_student": True,
    "courses": ["数学", "物理"],
    "score": None
}

# 转换为JSON字符串
json_str = json.dumps(data)
print(f"类型: {type(json_str)}")  # <class 'str'>
print(f"内容: {json_str}")
# 输出: {"name": "\u5f20\u4e09", "age": 25, "is_student": true, "courses": ["\u6570\u5b66", "\u7269\u7406"], "score": null}
-----------------
# 写入文件
with open('./data.json', 'w', encoding='utf-8') as f:
    json.dump(data, f,ensure_ascii=False,indent=2)  # 直接写入文件，无返回值

# 验证文件内容
with open('./data.json', 'r', encoding='utf-8') as f:
    content = f.read()
    print(f"文件内容: {content}")
```
### 常用参数示例

```
data = {"name": "张三", "age": 25, "scores": [90, 85]}

# ensure_ascii=False：正确显示中文
print(json.dumps(data, ensure_ascii=False))
# 输出：{"name": "张三", "age": 25, "scores": [90, 85]}

# indent：美化输出（格式化JSON）
print(json.dumps(data, ensure_ascii=False, indent=2))
# 输出：
# {
#   "name": "张三",
#   "age": 25,
#   "scores": [
#     90,
#     85
#   ]
# }

# separators：压缩JSON（去除空格）
print(json.dumps(data, separators=(',', ':')))
# 输出：{"name":"张三","age":25,"scores":[90,85]}

# sort_keys：按键排序
print(json.dumps(data, sort_keys=True))
```
## JSON Schema 验证
```
from jsonschema import validate

schema = {
    "type": "object",
    "properties": {
        "code": {"type": "integer"},
        "message": {"type": "string"},
        "data": {"type": "object"}
    },
    "required": ["code", "message"]
}

response_data = {"code": 200, "message": "success", "data": {}}
validate(instance=response_data, schema=schema)  # 无异常即通过
```
## 常见错误
```
# 错误1：json.loads 传入了文件对象，而不是字符串
with open('data.json') as f:
    data = json.loads(f)  # ❌ TypeError

# 正确：json.load(f) 直接传文件对象
with open('data.json') as f:
    data = json.load(f)

# 错误2：多次读取同一文件，忘记重置指针
with open('data.json') as f:
    data1 = json.load(f)   # 读取完毕，指针到末尾
    data2 = json.load(f)   # ❌ 失败，无内容可读
```

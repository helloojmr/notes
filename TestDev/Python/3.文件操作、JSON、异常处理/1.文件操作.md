## 测试中的应用

- **文件操作**：读取测试数据文件（CSV/Excel/TXT）、写入日志、保存测试报告、处理配置文件
- **JSON处理**：接口测试中解析请求/响应数据、构造测试数据、读取配置文件
- **异常处理**：增强脚本健壮性，优雅处理网络超时、文件不存在、断言失败等异常情况

## 文件分类

- 文本文件：以字符编码存储（如 UTF-8），适合人类阅读。如 txt、py、md、json
- 二进制文件：以字节存储，计算机直接使用，如图片、音视频、exe

## 文件操作
### 基本操作

- **打开文件**：`open(file，mode='r'，encoding=None)`
  - file（绝对路径/相对路径：`./` 当前，`../` 上一级目录
  - **返回一个文件操作对象 TextIOWrapper**
- **关闭文件**：`文件对象.close()`
  - 如果是写打开，close 会自动保存
- **读取文件**：`文件对象.read()`
  - 返回读取到的文件全部内容，类型为字符串
- **写文件**：`文件对象.write()`
  - 参数：写入文件的内容，类型字符串
  - 返回值：写入文件中的字符数
- `readline()`：读取一行
- `with` 语句：自动管理文件关闭，推荐使用
### with语句示例
```
with open('./tools.py', mode='a+', encoding='utf-8') as f:
    f.seek(0)
    print(f.read())
    f.write("\nhi")


with open('./tools.py', encoding='utf-8') as f:
    while True:
        buf = f.readline()
        if buf == '':
            # 文件读完后readline返回空字符串
            break
        else:
            print(buf, end='')

    # 等价写法：
    if buf:
        print(buf, end='')
        # 空即是False
    else:
        break


with open('./tools.py', encoding='utf-8') as f:
    for line in f:
        print(line, end='')
```

## 打开文件的方式

- r、w、a：文本方式打开，会对二进制文件进行编码转换
- rb、wb、ab：二进制方式打开，可以打开文本文件和二进制文件，二进制文件只能这样打开，无法传递 encoding 参数

## 打开模式详解

- **`r`**：只读（默认）；指针位置开头；文件不存在时报错
- **`w`**：只写；指针位置开头（清空）；文件不存在时创建
- **`a`**：追加；指针位置末尾；文件不存在时创建
- **`r+`**：读写；指针位置开头；文件不存在时报错
- **`w+`**：读写；指针位置开头（清空）；文件不存在时创建
- **`a+`**：读写；指针位置末尾；文件不存在时创建
- **`rb`**：二进制读；指针位置开头；文件不存在时报错
- **`wb`**：二进制写；指针位置开头（清空）；文件不存在时创建
- **`ab`**：二进制追加；指针位置末尾；文件不存在时创建

## 文件指针操作
### 常用方法

- `tell()`：返回当前文件指针位置（字节数）。
- `seek(offset, whence)`：移动文件指针。
  - `whence=0`：从文件开头偏移（默认）
  - `whence=1`：从当前位置偏移
  - `whence=2`：从文件末尾偏移
### seek示例
```
with open('test.txt', 'w+') as f:
    f.write('Hello World')
    f.seek(0)  # 回到开头才能读取
    print(f.read())  # Hello World
```

## 读取文件的几种方式
### 常用方法
- **`read()`**：一次性加载全部，大文件可能内存溢出，适合小文件
- **`readline()`**：每次一行，适合大文件逐行处理
- **`for line in f`**：每次一行，逐行处理最简洁
- **`readlines()`**：读取所有行到列表，一次性加载全部
- **最佳实践**：处理大日志文件时，用 `for line in f` 逐行读取，避免内存爆炸
### 逐行读取示例
```
with open('huge.log', 'r', encoding='utf-8') as f:
    for line in f:
        if 'ERROR' in line:
            print(line.strip())
```

## 写入文件的注意事项

- `write()` 不会自动换行，需要手动加 `\n`。
- `writelines()` 接受字符串列表，但也不会自动换行。
- 使用 `with` 语句，自动调用 `close()` 并刷新缓冲区

## 文件操作常见陷阱

```
# 陷阱1：忘记关闭文件（用with避免）
f = open('test.txt', 'w')
f.write('data')
# f.close() 忘记调用，可能导致数据未写入

# 陷阱2：读取后忘记seek，再次读取为空
with open('test.txt', 'r') as f:
    content = f.read()
    content2 = f.read()  # 空字符串！指针已在末尾

# 陷阱3：二进制和文本模式混用
with open('image.jpg', 'r') as f:  # ❌ 应该用 'rb'
    data = f.read()  # 可能解码错误
```

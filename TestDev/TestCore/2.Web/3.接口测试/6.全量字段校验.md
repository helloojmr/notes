## 全量字段校验

### 概念

- 校验接口响应数据的全部字段的**字段名、字段类型、字段值格式**完全符合预期。

### 校验流程

1. **定义 JSON Schema 校验格式**
  - 根据接口文档或需求，编写一个 Schema 文件(通常是一个 Python 字典)，描述期望的响应结构。
2. **比对接口实际响应数据**
  - 将接口返回的 JSON 数据与 Schema 进行比对，如果不符合，`jsonschema.validate()` 会抛出异常，说明哪个字段不匹配。

#### 实现

```
json_input = {'success': True, 'code': 10000, 'message': '操作成功！', 'data': '480a8dff-f78f-42d7-9604-6b5feae2d016'}
schema = {
    "type": "object",
    "properties": {
        "success": {
            "type": "boolean"
        },
        "code": {
            "type": "integer"
        },
        "message": {
            "type": "string"
        }
    },
    "required": ["success", "code", "message"]
}

jsonschema.validate(json_input, schema)
# 注意：示例中实际数据比 Schema 多了一个 data 字段，但 Schema 没有声明它，所以额外字段是允许的。
# 额外设置 "additionalProperties": false 以禁止额外字段。
```

### JSON Schema 重点关键字

#### type:数据类型约束

- 用于约束某个节点(字段或整个对象)的数据类型。
- `"integer"`：整数
- `"string"`：字符串
- `"object"`：JSON 对象(Python 字典)
- `"array"`：数组(Python 列表)
- `"number"`：整数或小数
- `"null"`：`None`
- `"boolean"`：布尔值
- 示例：`{"type":"string"}`

#### properties:定义对象的字段

- 当 `type` 为 `"object"` 时，用 `properties` 来具体描述对象内每个字段的校验规则。
- `properties` 是一个字典，键是字段名，值是字段的 Schema(可以嵌套)。
#### 示例

```
"properties": {
    "name": {"type": "string"},
    "age": {"type": "integer"}
}
```

#### required:必填字段列表

- 指定对象中必须存在的字段名(数组形式)，如果实际对象缺少这些字段，校验失败。
- 示例：`"required": ["name", "age"]`

#### const:固定值校验

- 要求字段的值必须等于某个指定的常量，例如接口返回的 `status` 字段必须为 `"success"`。
- 示例：`{"const": "success"}`

#### pattern:正则匹配字符串

- 当字段类型为字符串时，可以用 `pattern` 指定一个正则表达式，要求字符串必须匹配该模式。
#### UUID 格式示例

```
{
    "type": "string",
    "pattern": "^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$"
}
```

#### 基础正则

- 包含字符串：hello，如：hello,world
- 以字符串开头：^hello，如：hello,world
- 以字符串结尾：hello$，如：中国,hello
- 匹配 [] 内的任意一个字符：[0-9]、[a-z]、[A-Z]
- 匹配指定次数 {}：[0-9]{11} 匹配 11 位数字

### 完整 Schema 示例

#### JSON 数据示例

```
{
    "success": true,
    "code": 200,
    "message": "OK",
    "data": {
        "user_id": 12345,
        "token": "abc.def.ghi",
        "roles": ["admin", "user"]
    }
}
```

#### Schema 定义

```
schema = {
    "type": "object",
    "properties": {
        "success": {"type": "boolean"},
        "code": {"type": "integer"},
        "message": {"type": "string"},
        "data": {
            "type": "object",
            "properties": {
                "user_id": {"type": "integer"},
                "token": {
                    "type": "string",
                    "pattern": "^[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+\.[A-Za-z0-9_-]+$"
                },
                "roles": {
                    "type": "array",
                    "items": {"type": "string"}
                }
            },
            "required": ["user_id", "token", "roles"],
            "additionalProperties": False
        }
    },
    "required": ["success", "code", "message", "data"],
    "additionalProperties": False
}
```

## 接口对象封装

### 接口对象层

#### 定义

- **职责**：对接口进行封装，隐藏请求细节(URL、方法、参数组装、认证等)。
- **实现方式**：面向对象类封装实现(如 `UserAPI` 类封装 `login()`、`get_user_info()` 等方法)。

#### 实现

```
class LoginAPI:
    def __init__(self, base_url, session=None):
        self.base_url = base_url
        self.session = session or requests.Session()  # 复用session保持cookie
    def login(self, username, password, captcha=None):
        url = f"{self.base_url}/login"
        data = {
            "username": username,
            "password": password,
            "captcha": captcha
        }
        resp = self.session.post(url, data=data)
        return resp   # 返回原始响应对象，或进一步封装
```

### 测试用例层

#### 定义

- **职责**：编写具体的测试用例，关注**测试数据准备**和**断言**，不关心接口如何发送请求。
- **实现方式**：通常使用 `unittest` 或 `pytest` 框架，直接调用接口对象层的方法，然后对返回结果进行断言。

#### 实现

```
import unittest
from api.login import LoginAPI

class TestLogin(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.login_api = LoginAPI("http://example.com")

    def test_login_success(self):
        resp = self.login_api.login("valid_user", "valid_pass")
        self.assertEqual(resp.status_code, 200)
        self.assertEqual(resp.json().get("code"), 0)   # 假设业务码0表示成功

    def test_login_wrong_password(self):
        resp = self.login_api.login("valid_user", "wrong_pass")
        self.assertEqual(resp.status_code, 200)
        self.assertEqual(resp.json().get("code"), 1001)  # 假设1001表示密码错误
```

### 参数化(数据驱动)

#### 定义

- **核心思想**：将测试数据从测试代码中分离出来，存放在外部文件(JSON、YAML、Excel、CSV)中。同一个测试方法，通过加载不同的数据行来执行多个测试用例。
- **优点**：新增测试用例只需添加数据，无需修改代码；测试数据与逻辑分离，维护成本低。

#### 实现

```
import unittest
from ddt import ddt, data, unpack
from api.login import LoginAPI

@ddt
class TestLogin(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.login_api = LoginAPI("http://example.com")

    @data(
        ("valid_user", "valid_pass", 0),      # 成功用例
        ("valid_user", "wrong_pass", 1001),   # 密码错误
        ("", "valid_pass", 1002),             # 用户名为空
    )
    @unpack
    def test_login(self, username, password, expected_code):
        resp = self.login_api.login(username, password)
        self.assertEqual(resp.status_code, 200)
        self.assertEqual(resp.json().get("code"), expected_code)
```

### Session 使用注意事项

#### 坑:类属性共享 session

#### 问题说明

```
class TestLogin(TestCase):
    session = None  # ❌ 类属性：所有测试方法共享

    @classmethod
    def setUpClass(cls):
        cls.session = requests.Session()  # 整个测试类只创建一次

    def setUp(self):
        # 使用共享的session，可能会修改cookies
        LoginAPI.get_v(self.session)
        # 这个操作会影响后续所有测试！

    def test_login_001(self):
        resp = LoginAPI.login(self.session)
        comon_assert(self, resp, 200, 1, "登录成功")

def comon_assert(self, resp, status_code, status, msg):
    self.assertEqual(status_code, resp.status_code)
    self.assertEqual(status, resp.json().get("status"))
    self.assertIn(msg, resp.json().get("msg"))
```

#### 正确写法:实例独立

#### 正确做法

```
class TestLogin(TestCase):

    def setUp(self):
        # 为每个测试方法创建独立的session
        self.session = requests.Session()
        LoginAPI.get_v(self.session)

    def tearDown(self):
        if hasattr(self, 'session'):
            self.session.close()
        print(f"清理session: {id(self.session)}")

    def test_login_001(self):
        resp = LoginAPI.login(self.session)
        print(resp)
        comon_assert(self, resp, 200, 1, "登录成功")

def comon_assert(self, resp, status_code, status, msg):
    self.assertEqual(status_code, resp.status_code)
    self.assertEqual(status, resp.json().get("status"))
    self.assertIn(msg, resp.json().get("msg"))
```

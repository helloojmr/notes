## 性能测试工具对比

| 对比维度 | JMeter | Locust | LoadRunner |
| --- | --- | --- | --- |
| 语言/生态 | Java（Apache 开源） | Python | C/Java（商业） |
| 使用方式 | GUI + CLI（.jmx 脚本） | Python 代码编写场景 | Windows 控制器 GUI + 脚本录制 |
| 并发模型 | 线程组（线程模拟用户） | 协程（高并发开销小） | 虚拟用户 Vuser（多进程/多线程） |
| 录制方式 | 手动编写 / 录制 | 代码编写 | 协议级录制，自动生成脚本 |
| 协议支持 | HTTP/RPC/数据库，插件丰富 | HTTP（需编程扩展） | 企业协议最广（HTTP/DB/ERP/SAP 等） |
| 适用场景 | 标准接口、团队熟悉 JMeter | 复杂业务逻辑、需编程控制 | 企业级、传统行业大型项目 |
| 报告 | HTML 报告、聚合报告、图表 | 实时 Web 界面 + CSV 导出 | Analysis 强大的图表分析 |
| 与测试框架结合 | 一般（CLI 可接 CI） | 好（Python 生态） | 差（封闭商业工具） |
| 学习成本 | 中（GUI 上手快） | 中（会 Python 即可） | 高（协议多、脚本语言 C） |
| 价格 | 免费开源 | 免费开源 | 商业付费（昂贵） |

- **选型建议**：接口标准、团队熟悉 JMeter → 用 JMeter；业务复杂、需要代码定制并发逻辑、想和 Python 测试框架结合 → 用 Locust；企业级多协议、有预算、传统行业 → 用 LoadRunner。

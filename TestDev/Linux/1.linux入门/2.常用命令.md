## Linux 常用命令

### 命令格式与帮助
- 格式：`command [-options] [parameter]`
- 获取帮助：`command --help` 或 `man command`
- 常用快捷键：
  - `Ctrl + l`：清屏
  - `Ctrl + a`：光标到句首
  - `Ctrl + e`：光标到句尾
  - `Ctrl + c`：中断当前命令
  - `Ctrl + r`：历史命令搜索
  - `Tab`：自动补全
- `pwd`：查看当前目录的路径
- `clear`：清屏
- `which 工具名称`：查找工具的安装位置
- `echo`：回显
- `history`：查看历史命令
- `!!`：重复上一条命令（`sudo !!` 经典组合：上条命令权限不够时）

### 核心命令分类

#### 文件操作类
- **ls -lh**：人性化显示文件大小
- **du -sh \***：查看当前目录下各文件夹大小（磁盘满了排查用）
- **find / -name "*.log" -mtime -7**：找 7 天内修改的日志文件

#### 文本处理三剑客
- **grep**（搜索）
  - `grep -r "ERROR" /var/log/`：递归查找所有日志中的 ERROR
  - `grep -A5 -B5 "NullPointer" app.log`：显示错误前后 5 行（上下文）
- **awk**（列处理）
  - `awk '{print $1, $4}' access.log`：提取 IP 和时间列
  - `awk '$9 > 500 {print $0}' access.log`：找出状态码 >500 的请求
- **sed**（行处理）
  - `sed -i 's/oldip/newip/g' config.properties`：批量替换配置
  - `sed -n '10,20p' app.log`：查看第 10-20 行

#### 进程与端口
- **ps -ef | grep java**：找 Java 进程
- **netstat -anpt | grep 8080**：看谁占用了 8080 端口
- **lsof -i:8080**：更友好的查看方式
- **kill -9 PID**：强制杀进程（慎用）

#### 性能监控
- **top**：看 CPU、内存、负载（按 1 看每个核）
- **free -h**：看内存
- **df -h**：看磁盘
- **iostat**：看磁盘 IO
- **vmstat**：系统整体状况

### 网络命令

- **ping 地址**：测试网络连通性
- **curl URL**：发送 HTTP 请求（接口调试常用）
  - `curl -I URL`：只看响应头
  - `curl -X POST -d "data" URL`：发送 POST 请求
- **wget URL**：下载文件
- **ssh 用户@IP**：远程登录服务器
- **scp 文件 用户@IP:路径**：远程复制文件
- **rsync -av 源 目标**：增量同步（部署与备份常用）

### 软件包与服务管理

- **yum install / remove 包名**：CentOS/RHEL 软件包安装与卸载
- **apt install / remove 包名**：Ubuntu/Debian 软件包安装与卸载
- **rpm -qa**：查看已安装的 RPM 包
- **dpkg -l**：查看已安装的 DEB 包
- **systemctl start/stop/restart/status 服务名**：服务管理（现代方式）
- **systemctl enable/disable 服务名**：设置开机自启 / 取消自启
- **service 服务名 start/stop**：老式服务管理命令

### 文本处理补充命令

- **sort**：排序输出
- **uniq -c**：去重并统计次数（常与 sort 配合）
- **wc -l**：统计行数
- **cut -d',' -f1**：按分隔符截取列
- **tr 'a-z' 'A-Z'**：字符替换 / 大小写转换

### 磁盘与系统信息

- **uptime**：查看系统负载与运行时间
- **uname -a**：查看内核版本
- **date**：查看系统时间
- **lscpu**：查看 CPU 信息
- **who / last**：查看当前登录用户 / 登录记录

### 用户与权限命令

- **sudo 命令**：以管理员权限执行
- **su - 用户名**：切换用户
- **chmod 权限 文件**：修改文件权限
- **chown 用户:组 文件**：修改文件属主
- **useradd / userdel 用户名**：新增 / 删除用户
- **passwd**：修改密码

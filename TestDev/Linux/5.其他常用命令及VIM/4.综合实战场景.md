## 场景1：查找大文件并清理
```
# 找出根目录下大于500M的文件
find / -type f -size +500M -exec ls -lh {} \; 2>/dev/null
# 确认后删除（小心！）
find /tmp -name "core.*" -size +1G -exec rm -f {} \;
```

## 场景2：批量重命名文件（结合sed）

```
# 将所有.txt文件重命名为.bak
for file in *.txt; do
    mv "$file" "${file%.txt}.bak"
done
# 或用rename命令（如果安装）
rename 's/\.txt$/\.bak/' *.txt
```
## 场景3：快速部署应用

```
# 本地打包
tar -zcvf app.tar.gz --exclude="*.log" --exclude=".git" app/
# 上传并解压
scp app.tar.gz user@server:/opt/
ssh user@server "cd /opt && tar -zxvf app.tar.gz && ln -snf app app_current"
```
## 场景4：编辑远程文件（ssh + vim）

```
vim scp://user@server//etc/nginx/nginx.conf
# 或使用 vim 直接编辑远程文件（需支持）
```

## 安装与升级测试

### 安装场景

#### 首次安装

- 应用市场 / APK 直装 / 扫码安装，安装成功后可正常启动。

#### 覆盖安装

- 旧版本 → 新版本，本地数据、登录态保留。

#### 降级安装

- 新版本 → 旧版本，Android 一般不允许直接降级，需先卸载。

#### 签名校验

- 包名相同但签名不一致时安装失败，提示"应用未安装"或冲突。

### 异常场景

- 存储空间不足时的安装提示。
- 安装过程中断（拔线 / 断电 / 手动取消），再次安装应正常。
- 重复安装同名应用（不同来源）的冲突处理。

### 卸载场景

- 正常卸载后**无残留**：缓存、数据、桌面图标全部清除。
- 卸载过程中取消，应用状态不受影响。
- 卸载后重新安装，首次启动流程正常。

### 升级方式

#### 应用市场静默升级

- 用户无感知自动更新。

#### 应用内提示升级

- 弹窗提示，用户选择立即 / 稍后。

#### 强制升级

- 旧版本不可用，必须升级后才能使用。

#### 热更新

- 不发版修复，验证本地资源 / 代码更新逻辑。

### 升级测试关注点

- 升级后数据保留：登录态、设置项、本地缓存、收藏记录。
- 升级中断：下载中断、安装中断，应可恢复或提示重试。
- 增量更新 vs 全量更新：包体积、流量消耗对比。
- 版本兼容：新版本产生的数据在旧版本中不应出现异常（一般不支持回退）。

### 实战要点

- 升级流程自动化：安装旧版本 → 触发升级 → 校验数据保留与功能正常。

## 兼容性与弱网测试

### 兼容性测试维度

- **机型 / 厂商**：华为、小米、OPPO、vivo、荣耀等主流厂商。
- **系统版本**：Android 各版本、HarmonyOS。
- **分辨率 / 屏幕**：720P / 1080P / 2K，全面屏、刘海屏、折叠屏、平板。
- **网络制式**：4G / 5G / WiFi。
- **芯片平台**：高通、联发科、麒麟等。

### 兼容性测试手段

- **真机矩阵**：按 TOP 机型清单覆盖核心功能冒烟 + UI 走查。
- **云测平台**：Testin、WeTest、阿里云测，批量执行兼容性用例。
- **模拟器**：覆盖系统版本差异，真机差异需真机补充。

### 实战要点

- 兼容性用例脚本化，接入云测平台批量跑，自动收集崩溃 / UI 异常截图。

### 弱网模拟手段

#### Fiddler / Charles 限速

- 通过 throttle 模拟 2G / 3G / 弱 WiFi 网速。

#### 开发者选项限速

- Android 开发者选项自带网络限速（部分机型）。

#### 真实网络切换

- WiFi ↔ 4G 切换、飞行模式、断网重连。

### 弱网测试关注点

- 请求超时、超时重试机制。
- 弱网下 UI 状态：加载中、失败重试、无响应提示。
- 网络恢复后的数据同步与一致性。
- 图片 / 视频在弱网下的加载与占位处理。

### 面试话术

- 弱网测试用 Fiddler / Charles 限速模拟，重点验证**超时提示、重试机制、断网恢复后的数据同步**。

## 中断与权限测试

### 中断类型

#### 系统事件

- 来电、短信、通知、闹钟、低电量、充电。

#### 界面操作

- 锁屏 / 解锁、Home 键切换、横竖屏切换。

#### 异常情况

- 杀进程、系统重启、应用崩溃恢复。

### 中断测试关注点

- 中断后回到 App 的状态：页面恢复、数据不丢失、登录态保持。
- 中断期间无崩溃、无 ANR。
- 来电挂断后返回应用，正在进行的操作（输入、上传、播放）状态正确。

### 权限测试场景

#### 首次启动弹窗

- 权限申请时机、文案说明、是否可拒绝。

#### 拒绝权限后

- 功能降级或引导开启，不应闪退。

#### 撤回权限

- 设置中关闭权限后，App 对应功能的表现。

#### 权限最小化

- 仅申请业务必要权限，不申请无关敏感权限。

#### 后台权限

- 后台定位、后台运行的权限提示与合规。

### 实战要点

- 自动化中处理权限弹窗：Appium 的 `autoGrantPermissions`、uiautomator 自动点击授权。

## 手势与交互测试

### 手势类型

- 点击、长按、双击、滑动、双指缩放、多点触控、侧滑返回。

### 测试关注点

- 手势冲突与误触：相邻按钮、边缘手势与业务手势。
- 横竖屏切换：布局自适应、数据保留。
- 物理按键：返回键、Home 键、多任务键、音量键。
- 系统适配：深色模式、字体大小、无障碍（TalkBack）。

## 面试高频题

- **Q**：App 兼容性测试如何做？**A**：先列 TOP 机型 / 系统版本 / 分辨率矩阵，核心功能真机冒烟 + UI 走查，再用云测平台批量执行，自动收集崩溃与截图。
- **Q**：弱网测试如何模拟？**A**：Fiddler / Charles 限速模拟 2G / 3G / 弱 WiFi，或开发者选项限速；重点验证超时提示、重试机制、断网恢复后的数据同步。
- **Q**：安装与升级测试关注什么？**A**：首次 / 覆盖 / 降级安装，签名校验，存储不足与中断；升级关注数据保留、升级中断恢复、强制升级与热更新。
- **Q**：App 权限测试怎么做？**A**：覆盖首次弹窗、拒绝后的降级表现、授权后撤回、权限最小化与后台权限合规。
- **Q**：中断测试有哪些场景？**A**：来电、短信、通知、锁屏、低电量、杀进程、系统重启；关注回到应用后的页面状态、数据与登录态是否保持。

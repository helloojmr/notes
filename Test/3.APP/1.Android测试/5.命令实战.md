## 应用信息获取

### adb 获取包名与 Activity

#### 场景1：获取当前应用的包名和 Activity（adb）

```
# 方法1：dumpsys window
adb shell dumpsys window | findstr mCurrentFocus
# 方法2：logcat 抓取启动信息
adb logcat -c
# 手动打开应用，然后执行
adb logcat -d | findstr "START"
```

### hdc 获取包名与 Ability

#### 场景5：获取当前应用的包名和 Ability（hdc）

```
# 方法1：查看 Ability 栈
hdc shell aa dump -l
# 方法2：查看窗口焦点（找 mCurrentFocus 对应窗口）
hdc shell hidumper -s WindowManagerService -a '-a'
```

## 启动与性能测试

### adb 冷启动与清理启动

#### 场景2：应用冷启动时间测试（adb）

```
# 多次测试取平均值
for i in {1..5}; do
    adb shell am force-stop com.example.app
    adb shell am start -W com.example.app/.MainActivity | grep "TotalTime"
done
```

#### 场景4：清理应用缓存后首次启动（adb）

```
adb shell pm clear com.example.app
adb shell am start -W com.example.app/.MainActivity
```

### hdc 冷启动与清理启动

#### 场景6：应用冷启动时间测试（hdc）

```
# hdc 没有 am start -W 的等效参数，用 time 粗测 + hilog 精确分析
for i in {1..5}; do
    hdc shell aa force-stop com.example.app
    time hdc shell aa start -a EntryAbility -b com.example.app
done
# 精确分析：抓取 hilog 中 AbilityManager / AppManager 的启动耗时日志
hdc hilog | grep -E "AbilityManager|AppManager" > startup.log
```

#### 场景8：清理应用缓存后首次启动（hdc）

```
# -c 清除缓存，-d 清除全部数据（相当于重置应用）
hdc shell bm clean -n com.example.app -c
hdc shell aa start -a EntryAbility -b com.example.app
```

## 性能监控

### adb CPU 与内存监控

#### 场景3：监控应用 CPU 和内存变化（adb）

```
# 持续监控（每隔2秒输出一次）
while true; do
    adb shell top -n 1 | grep com.example.app
    adb shell dumpsys meminfo com.example.app | grep "Total RAM"
    sleep 2
done
```

### hdc CPU 与内存监控

#### 场景7：监控应用 CPU 和内存变化（hdc）

```
# 持续监控（每隔2秒输出一次）
while true; do
    hdc shell top -n 1 | grep com.example.app
    hdc shell hidumper --mem | grep -A 3 com.example.app
    sleep 2
done
```

## 问题定位与自动化冒烟

### hdc 崩溃与 ANR 定位

#### 场景9：抓取崩溃与 ANR 日志（hdc）

```
# 过滤崩溃日志（按标签或错误级别）
hdc hilog -T "CRASH" > crash.log
hdc hilog -L E > error.log
# ANR 堆栈分析
hdc shell cat /data/anr/traces.txt
```

### hdc 安装与冒烟

#### 场景10：安装 HAP 并启动（hdc 自动化冒烟）

```
# 安装被测应用
hdc install app.hap
# 拉起应用
hdc shell aa start -a EntryAbility -b com.example.app
# 截图归档
hdc shell snapshot_display -f /data/local/tmp/screen.png
hdc file recv /data/local/tmp/screen.png ./
```

## 设备连接与管理

### 连接与断开

#### hdc list targets：查看已连接设备列表

- `-v` 显示详细信息。

#### hdc -t <设备ID> shell：指定设备执行命令

- 多设备时使用。

#### hdc tconn <ip>:<port>：通过网络连接设备

- 默认端口 8710。

#### hdc tmode usb / port <端口>：切换 USB / 网络连接方式

### 服务与版本

#### hdc kill / hdc start：终止 / 启动 hdc 服务

- 设备识别异常时重启服务。

#### hdc -v：查看 hdc 版本

## 应用安装与包管理

### 安装与卸载

#### hdc install：安装 HAP 应用包

- `hdc install <xxx.hap>`
- `-r`：覆盖安装（保留数据）
- `-d`：允许降级安装
- `-g`：授予应用权限

#### hdc uninstall：卸载应用

- `hdc uninstall <包名>`
- `-k`：卸载但保留数据

### 包管理（bm）

#### bm install：通过包管理工具安装

- `hdc shell bm install -p <hap路径>`

#### bm uninstall：通过包管理工具卸载

- `hdc shell bm uninstall -n <包名>`

#### bm dump：查看应用信息

- `hdc shell bm dump -a`：列出所有已安装应用
- `hdc shell bm dump -n <包名>`：查看指定应用信息

### 应用启动与停止（Ability）

#### aa start：启动应用

- `hdc shell aa start -a <Ability名> -b <包名>`

#### aa force-stop：强制停止应用

- `hdc shell aa force-stop <包名>`

#### aa dump：查看 Ability 信息

- `hdc shell aa dump -l`（列出所有 Ability）

## 系统信息获取

### 设备与参数

#### 设备信息

- `hdc shell param get const.product.name`

### CPU / 内存

#### CPU 使用

- `hdc shell hidumper --cpuusage`

#### 内存详情

- `hdc shell hidumper --mem`

### 进程与服务

#### 进程资源占用

- `hdc shell top -n 1`

#### 服务信息

- `hdc shell hidumper -s <服务名>`

## 文件操作与截图

### 文件操作

#### 上传文件

- `hdc file send <本地路径> <设备路径>`

#### 下载文件

- `hdc file recv <设备路径> <本地路径>`

#### 设备端文件操作

- `hdc shell ls / rm / mkdir`

#### 查看文件内容

- `hdc shell cat <路径>`

### 截图

#### 截图保存到设备

- `hdc shell snapshot_display -f /data/local/tmp/screen.png`

#### 拉取到电脑

- `hdc file recv /data/local/tmp/screen.png ./`

## 日志抓取

### 基础操作

#### 查看实时日志

- `hdc hilog`（类似 adb logcat）

#### 清空日志缓冲区

- `hdc hilog -c`

#### 保存日志到本地

- `hdc hilog > app.log`

### 过滤与定位

#### 按标签过滤

- `hdc hilog -T <标签>`（如 AppManager）

#### 按日志级别过滤

- `hdc hilog -L <级别>`（D/I/W/E）

#### 查看 ANR 堆栈

- `hdc shell cat /data/anr/traces.txt`（定位无响应问题）

## 测试应用场景与 adb 对照

### 测试应用场景

#### 环境准备

- 设备开启开发者模式，USB 连接后 `hdc list targets` 确认识别。

#### 自动化冒烟

- `hdc install` 安装被测 HAP，`hdc shell aa start` 拉起应用。

#### 崩溃 / ANR 定位

- `hdc hilog -T "CRASH"` 过滤崩溃日志，`hdc shell cat /data/anr/traces.txt` 分析 ANR。

#### 性能验收

- `hdc shell top`、`hdc shell hidumper --mem` 采集 CPU / 内存基线。

#### 日志归档

- `hdc hilog > app.log` 保存日志，随缺陷一起提交。

### hdc 与 adb 命令对照

- 设备列表：hdc list targets ↔ adb devices
- 进入 shell：hdc shell ↔ adb shell
- 安装应用：hdc install ↔ adb install
- 卸载应用：hdc uninstall ↔ adb uninstall
- 上传 / 下载文件：hdc file send/recv ↔ adb push/pull
- 查看日志：hdc hilog ↔ adb logcat
- 系统信息：hdc shell hidumper ↔ adb shell dumpsys
- 启动 / 停止应用：hdc shell aa ↔ adb shell am
- 包管理：hdc shell bm ↔ adb shell pm
- 连接网络设备：hdc tconn ↔ adb connect

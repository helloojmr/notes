## 设备连接与管理

### 连接与断开

#### adb devices：查看已连接设备

#### adb connect 192.168.1.100：连接网络设备

#### adb disconnect：断开连接

### 服务与重启

#### adb kill-server / start-server：重启 adb 服务

- 解决设备 offline 问题。

#### adb reboot：重启设备

## 应用安装与包管理

### 安装与卸载

#### adb install：安装应用

- `adb install app.apk`：普通安装
- `adb install -r app.apk`：覆盖安装（保留数据）
- `adb install -t app.apk`：允许安装测试包

#### adb uninstall：卸载应用

- `adb uninstall com.example.app`：卸载应用
- `adb uninstall -k com.example.app`：卸载但保留数据

### 包管理（pm）

#### 列出包名

- `adb shell pm list packages`：列出所有包名
- `adb shell pm list packages -3`：只显示第三方应用
- `adb shell pm list packages -s`：只显示系统应用

#### 查看安装路径

- `adb shell pm path com.example.app`：查看 apk 安装路径

#### 清除应用数据

- `adb shell pm clear com.example.app`：清除应用数据（相当于重置）

#### 禁用 / 启用应用

- `adb shell pm disable com.example.app`：禁用应用
- `adb shell pm enable com.example.app`：启用应用

## Activity 管理

### 启动与停止

#### 启动应用

- `adb shell am start -n com.example.app/.MainActivity`（需要知道主 Activity）

#### 获取应用启动时间

- `adb shell am start -W -S com.example.app/.MainActivity`（-W 输出启动时间，-S 强制停止后再启动）

#### 强制停止应用

- `adb shell am force-stop com.example.app`

### 状态查询

#### 获取当前聚焦的 Activity

- `adb shell dumpsys window | findstr mCurrentFocus`（快速定位前台应用包名，输出示例：`mCurrentFocus=Window{xxx com.example.app/.MainActivity}`）

## 系统信息获取

### CPU 信息

#### 实时 CPU 占用

- `adb shell top -n 1 | findstr "包名"`

#### 系统 CPU 统计

- `adb shell dumpsys cpuinfo`

### 内存信息

#### 指定应用内存详情

- `adb shell dumpsys meminfo com.example.app`

#### 系统内存总览

- `adb shell dumpsys meminfo`

### 电池信息

#### 查看电池状态

- `adb shell dumpsys battery`

#### 电池统计

- `adb shell dumpsys batterystats`（需先重置）

### 网络流量

#### 获取 userId

- `adb shell dumpsys package com.example.app | findstr "userId"`

#### 上行流量（字节）

- `adb shell cat /proc/uid_stat/[userId]/tcp_snd`

#### 下行流量

- `adb shell cat /proc/uid_stat/[userId]/tcp_rcv`

## 日志抓取

### 基础操作

#### 清空日志缓冲区

- `adb logcat -c`

#### 保存所有日志

- `adb logcat > app.log`

#### 带时间戳的日志

- `adb logcat -v time`

### 过滤日志

#### 过滤错误日志

- `adb logcat | findstr "ERROR"`

#### 只显示指定 TAG

- `adb logcat -s "ActivityManager"`

#### 只查看崩溃日志

- `adb logcat -b crash`

#### 过滤指定应用日志

- 应用日志专用命令（过滤包名）：`adb logcat --pid=$(adb shell pidof -s com.example.app)`

## 文件操作与截图

### 文件操作

#### 上传文件

- `adb push local.txt /sdcard/`

#### 下载文件

- `adb pull /sdcard/remote.txt ./`

#### 查看设备文件

- `adb shell ls /sdcard/`

#### 删除设备文件

- `adb shell rm /sdcard/test.txt`

### 截图与录屏

#### 截图

- `adb shell screencap /sdcard/screen.png` 保存到设备，再 `adb pull /sdcard/screen.png ./` 拉取到电脑

#### 录屏

- `adb shell screenrecord /sdcard/video.mp4`（Ctrl+C 停止），再 `adb pull /sdcard/video.mp4 ./`

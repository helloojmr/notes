## 关联是什么

- **定义**：后一个请求需要前一个请求响应中的**动态值**(token、订单号、session ID)，先把值提取出来，再给后面的请求引用。
- **为什么不能写死**：服务端每次生成的动态值都不同，写死必然失败。
- **三步法**：找依赖 → 提取 → 引用。
- **对应代码**：`token = resp.json()["data"]["token"]` 存变量 → 下一请求 `headers={"Authorization": f"Bearer {token}"}`。
- **测开**：关联是接口/性能自动化最核心的难点，token 链路是标准场景。

## 关联三步详解

### 第一步:找依赖

- 看接口文档或抓包，找出"这个参数的值是前面哪个接口返回的"。
- 常见依赖：token、订单号、用户 ID、验证码、临时文件路径。

### 第二步:提取(后置处理器)

- **JSON 提取器(JSON Extractor)**
  - 适用：响应是 JSON，最常用。
  - 配置：变量名、JSONPath 表达式、默认值。
  - JSONPath 语法：`$` 根节点、`.` 子节点、`[0]` 数组下标、`$.data.token` 表示取 data 下的 token。
  - 对应代码：`resp.json()["data"]["token"]`。
- **正则表达式提取器(Regular Expression Extractor)**
  - 适用：响应不是 JSON(HTML、XML 文本)，或 JSON 里用正则更顺手。
  - 配置：引用名称、正则表达式、模板 `$1$`、匹配数字(0=随机/1=第1个)、默认值。
  - 正则示例：`"token":"(.*?)"`，括号里是要提取的部分，`$1$` 取第一个括号。
  - 对应代码：`re.search(r'"token":"(.*?)"', text).group(1)`。
- **XPath 提取器**：响应是 XML 时用，了解即可。

### 第三步:引用

- 提取成功后用 `${变量名}` 引用，可出现在路径、参数、Body Data、Header 里。
- **同线程组内**：直接 `${token}` 引用。
- **跨线程组**：普通变量传不过去，用 `${__setProperty(token,${token},)}` 写成全局属性，目标线程组 `${__P(token)}` 读取。

## 提取失败排查

- 默认值填一个明显标记(如 `NOTFOUND`)：若请求里出现 NOTFOUND，说明没提取到。
- 用查看结果树核对实际响应，手动验证 JSONPath/正则对不对。
- 检查作用域：后置处理器必须挂在**被提取的那个请求**下面，不是挂在引用的请求下。
- 多值响应：匹配数字选 0(随机)或指定下标，别默认取错。

## 测开视角

- 关联 + 参数化是 JMeter 脚本两大支柱：**参数化管"数据从外部来"，关联管"数据从上一个响应来"**。
- 正则和 JSONPath 二选一：JSON 响应优先 JSONPath(可读性强)；文本/HTML 响应用正则。
- 面试话术：判断要不要关联——写死一个值跑一遍，报错再看响应，值每次不同就是要关联。

## 实战案例

### 案例一：登录拿 token → 压测订单查询(JSON 提取)

- 场景：订单接口需要登录返回的 token，模拟"登录一次，后续带头"。
- 配置步骤：
  - 登录请求(SetUp 线程组或普通请求) → 添加后置处理器 JSON 提取器
    - 变量名 `token`、JSONPath `$.data.token`、默认值 `NOTFOUND`
  - 订单请求 Header Manager：`Authorization: Bearer ${token}`(同线程组直接引用)
  - 跨线程组时：登录处 `${__setProperty(token,${token},)}`，订单处 `${__P(token)}`
- 验证：查看结果树里订单请求的 Authorization 头是真实 token，不是 NOTFOUND。

### 案例二：正则提取订单号

- 场景：下单接口返回 HTML，订单号在 `id="orderNo" value="ORD123456"` 里。
- 配置：正则表达式 `id="orderNo" value="(.*?)"`，引用名称 `orderNo`，模板 `$1$`。
- 引用：后续查询订单请求路径 `/api/order/${orderNo}`。

## 面试高频题

- **Q**：什么是关联？什么时候用？**A**：把前一个请求响应中的动态值提取出来供后续请求使用；接口间有数据依赖、值每次变化时用，典型如 token 链路。
- **Q**：JSON 提取器和正则提取器怎么选？**A**：响应是 JSON 用 JSON 提取器(JSONPath 可读性强)；非 JSON 文本/HTML 用正则提取器。
- **Q**：提取不到值怎么排查？**A**：默认值设 NOTFOUND 观察是否被替换；查看结果树核对响应与表达式；检查后置处理器是否挂在正确的请求下。
- **Q**：跨线程组传参怎么做？**A**：普通变量组内有效，用 `__setProperty` 写全局属性 + `__P` 读取。
- **Q**：关联和参数化的区别？**A**：参数化数据来自外部文件/函数/数据库，关联数据来自前一个请求的响应；一个管"外部喂数据"，一个管"响应取数据"。

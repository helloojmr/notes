## 作用

### 校验测试数据
- 有些接口的操作会修改数据库，但响应中并不包含修改后的字段值
删除员工接口：调用成功后，响应可能只返回 `{"code": 0, "message": "success"}`，但我们需要确认数据库中对应的员工记录确实被删除了（或标记为已删除）。这时必须查询数据库来验证。

### 构造测试数据
- 测试数据可能是一次性的，或者测试前无法保证数据存在
- 添加员工接口使用的手机号：
手机号不能重复，每次测试都需要用一个新的手机号。如果接口对手机号唯一性有要求，我们需要提前在数据库中清理或准备可用的手机号。
- 查询员工接口使用的员工 id：
测试查询前，必须确保某个员工 ID 在数据库中存在，否则查询会返回空。我们可以先插入一条员工记录，获取其 ID，然后用它来测试查询接口。

## 基本流程
### 开始 → 创建 connection → 获取 cursor → 执行 CURD → 关闭 cursor → 关闭 connection → 结束

### 关于游标（cursor）

- 游标是执行 SQL 和获取结果的句柄。一个连接可以创建多个游标，分别执行不同的操作。
- 常用游标方法
  - **fetchone()**：获取结果集的下一行。
  - **fetchmany(size)**：获取接下来的 `size` 行。
  - **fetchall()**：获取所有剩余行。
  - **cursor.rownumber**：当前游标位置（行索引），可以通过赋值来重置位置（如 `cursor.rownumber = 0` 回到开头，但某些数据库驱动可能不支持，需谨慎使用）。

### CURD 操作与事务控制

#### 定义
- **查询**：执行后使用 `fetch*` 系列方法获取数据，无需提交事务。
- **增删改**：这些操作会修改数据库，必须调用 **conn.commit()** 提交事务，更改才会永久生效。
  - 如果操作失败或需要撤销，可以调用 **conn.rollback()** 回滚到事务开始前的状态。
- **事务**：是关系型数据库的核心特性，确保一组操作要么全部成功，要么全部失败。在自动化测试中，我们经常利用事务来**隔离测试数据**：
  - 在测试开始时开启事务，执行数据准备和接口调用，然后验证结果，最后回滚事务，这样不会污染数据库。
  - 或者，测试结束后通过 DELETE 语句清理数据，但事务回滚更干净。

#### 实现：查询
```
# 查询
import pymysql
conn = pymysql.connect(host='localhost', user='root', password='123456', database='test')
cursor = conn.cursor(pymysql.cursors.DictCursor)  # 使用字典游标

try:
    cursor.execute("SELECT id, name FROM users WHERE age > %s", (18,))
    results = cursor.fetchall()  # 获取所有成年用户
    for row in results:
        print(f"ID: {row['id']}, Name: {row['name']}")
finally:
    cursor.close()
    conn.close()  # 确保资源释放
```

#### 实现：插入
```
# 插入数据
import pymysql

conn = pymysql.connect(
    host='localhost',
    user='root',
    password='123456',
    database='test'
)
cursor = conn.cursor(pymysql.cursors.DictCursor)

try:
    # 插入单条数据
    cursor.execute(
        "INSERT INTO users (name, age, email) VALUES (%s, %s, %s)",
        ('李四', 28, 'lisi@example.com')
    )

    # 插入多条数据（使用 executemany 提高效率）
    users_data = [
        ('王五', 30, 'wangwu@example.com'),
        ('赵六', 22, 'zhaoliu@example.com'),
        ('孙七', 35, 'sunqi@example.com')
    ]
    cursor.executemany(
        "INSERT INTO users (name, age, email) VALUES (%s, %s, %s)",
        users_data
    )

    # 获取刚插入数据的主键ID（针对单条插入）
    new_id = cursor.lastrowid
    print(f"新插入记录的主键ID: {new_id}")

    # 获取受影响的行数
    affected_rows = cursor.rowcount
    print(f"受影响的行数: {affected_rows}")

    # 提交事务（重要！）
    conn.commit()
    print("数据插入成功")

except Exception as e:
    # 发生错误时回滚
    conn.rollback()
    print(f"插入数据时发生错误: {e}")
finally:
    cursor.close()
    conn.close()
```

#### 实现：更新
```
# 更新数据
import pymysql

conn = pymysql.connect(
    host='localhost',
    user='root',
    password='123456',
    database='test'
)
cursor = conn.cursor(pymysql.cursors.DictCursor)

try:
    # 更新指定条件的数据
    cursor.execute(
        "UPDATE users SET age = %s, email = %s WHERE name = %s",
        (29, 'new_email@example.com', '李四')
    )

    # 获取受影响的行数
    affected_rows = cursor.rowcount
    print(f"更新了 {affected_rows} 条记录")

    if affected_rows > 0:
        # 查询更新后的数据验证
        cursor.execute(
            "SELECT * FROM users WHERE name = %s",
            ('李四',)
        )
        updated_user = cursor.fetchone()
        print(f"更新后的用户信息: {updated_user}")

    # 批量更新（根据条件更新多条记录）
    cursor.execute(
        "UPDATE users SET active = %s WHERE age > %s",
        (1, 25)  # 年龄大于25的用户设为活跃状态
    )
    print(f"批量更新了 {cursor.rowcount} 条记录")

    # 提交事务
    conn.commit()
    print("数据更新成功")

except Exception as e:
    conn.rollback()
    print(f"更新数据时发生错误: {e}")
finally:
    cursor.close()
    conn.close()
```

#### 实现：删除
```
# 删除数据
import pymysql

conn = pymysql.connect(
    host='localhost',
    user='root',
    password='123456',
    database='test'
)
cursor = conn.cursor(pymysql.cursors.DictCursor)

try:
    # 先查询要删除的数据（可选，用于确认）
    cursor.execute(
        "SELECT * FROM users WHERE age < %s",
        (20,)
    )
    users_to_delete = cursor.fetchall()
    print(f"即将删除以下 {len(users_to_delete)} 条记录:")
    for user in users_to_delete:
        print(f"  ID:{user['id']}, 姓名:{user['name']}, 年龄:{user['age']}")

    # 执行删除（注意：自动化脚本中不能用 input() 交互确认，会阻塞执行；如需确认请放在用例层控制）
    if len(users_to_delete) > 0:
        cursor.execute(
            "DELETE FROM users WHERE age < %s",
            (20,)
        )
        affected_rows = cursor.rowcount
        print(f"成功删除 {affected_rows} 条记录")

        # 提交事务
        conn.commit()
    else:
        print("没有符合条件的记录可删除")

except Exception as e:
    conn.rollback()
    print(f"删除数据时发生错误: {e}")
finally:
    cursor.close()
    conn.close()
```

#### 实现：事务处理（银行转账）
```
# 事务处理示例：银行转账（需要同时更新两个账户）
import pymysql

conn = pymysql.connect(
    host='localhost',
    user='root',
    password='123456',
    database='bank_db'
)
cursor = conn.cursor(pymysql.cursors.DictCursor)

try:
    # 开始一个事务：PyMySQL 默认 autocommit=False，执行 SQL 即处于事务中，无需显式 begin()
    # 注意：PyMySQL 的 Connection 没有 begin() 方法，调用会报 AttributeError

    # 设置转账参数
    from_account = '1001'
    to_account = '1002'
    amount = 500.00

    # 1. 检查转出账户余额是否充足
    cursor.execute(
        "SELECT balance FROM accounts WHERE account_no = %s FOR UPDATE",
        (from_account,)
    )
    from_account_data = cursor.fetchone()

    if not from_account_data:
        raise Exception(f"转出账户 {from_account} 不存在")

    if from_account_data['balance'] < amount:
        raise Exception(f"转出账户余额不足。当前余额: {from_account_data['balance']}")

    # 2. 执行转账：从转出账户扣款
    cursor.execute(
        "UPDATE accounts SET balance = balance - %s WHERE account_no = %s",
        (amount, from_account)
    )

    # 3. 执行转账：向转入账户加款
    cursor.execute(
        "UPDATE accounts SET balance = balance + %s WHERE account_no = %s",
        (amount, to_account)
    )

    # 4. 记录交易流水
    cursor.execute(
        """INSERT INTO transactions
           (from_account, to_account, amount, type)
           VALUES (%s, %s, %s, %s)""",
        (from_account, to_account, amount, 'TRANSFER')
    )

    # 提交事务（只有所有操作都成功才提交）
    conn.commit()
    print("转账成功！")

except Exception as e:
    # 任何一步失败都回滚整个事务
    conn.rollback()
    print(f"转账失败，已回滚: {e}")
finally:
    cursor.close()
    conn.close()
```

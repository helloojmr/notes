## 数据库连接配置

### JSON 配置

#### 定义

#### 说明
- **作用**：数据库连接参数通过 JSON 配置文件管理，避免硬编码，便于不同环境切换。
- **配置项**：host、user、password、database、port、charset、pool_size、connect_timeout、read_timeout、write_timeout、autocommit

#### 实现
```
{
  "host": "localhost",
  "user": "your_username",
  "password": "your_password",
  "database": "your_database",
  "port": 3306,
  "charset": "utf8mb4",
  "pool_size": 10,
  "connect_timeout": 10,
  "read_timeout": 30,
  "write_timeout": 30,
  "autocommit": false
}
```

### 工具类设计特点

- **单例模式**
  - 说明：全局只有一个数据库工具实例
  - 优势：避免重复创建连接，统一管理
- **连接池**
  - 说明：内置简单连接池实现
  - 优势：提高性能，避免频繁创建连接
- **上下文管理器**
  - 说明：支持 `with` 语句自动管理资源
  - 优势：确保连接和游标正确关闭
- **事务支持**
  - 说明：完整的事务管理
  - 优势：保证数据一致性
- **类型提示**
  - 说明：完整的类型注解
  - 优势：提高代码可读性和 IDE 支持
- **配置管理**
  - 说明：支持文件配置和代码配置
  - 优势：灵活切换不同环境
- **错误处理**
  - 说明：完善的异常处理和日志记录
  - 优势：便于问题排查
- **分页查询**
  - 说明：内置分页查询方法
  - 优势：简化分页逻辑
- **批量操作**
  - 说明：支持批量插入和更新
  - 优势：提高大数据量操作性能
- **监控统计**
  - 说明：数据库监控和统计功能
  - 优势：便于性能分析和优化

### requests.get() vs pymysql.connect()

- **核心设计模式**
  - **`requests.get()`（模块级函数模式）**：提供极简语法糖的模块函数
  - **`pymysql.connect()`（工厂函数模式）**：创建复杂对象的工厂函数
- **主要目的**
  - **`requests.get()`（模块级函数模式）**：发起一个 HTTP GET 请求，这是一个**动作**。
  - **`pymysql.connect()`（工厂函数模式）**：创建一个数据库连接对象，这是一个**对象**。
- **返回的对象**
  - **`requests.get()`（模块级函数模式）**：一个 **`Response` 类的实例**，它包含了请求的**全部结果**（状态码、头、体等）。
  - **`pymysql.connect()`（工厂函数模式）**：一个 **`Connection` 类的实例**，它本身是一个**用于后续操作的工具**。
- **类比**
  - **`requests.get()`（模块级函数模式）**：像"点外卖"这个动作。你说"我要点一份披萨"（`get(url)`），平台（`requests` 模块）处理所有复杂流程（构造请求、发送、接收），最后把**完整的披萨餐盒**（`Response` 对象）送到你手里。
  - **`pymysql.connect()`（工厂函数模式）**：像"开通一条电话专线"。你申请开通（`connect(...)`），电话公司（`pymysql`）为你建立好一条**持续的物理线路**（`Connection` 对象），之后你可以用这条线路进行多次通话（执行 SQL）。
- **内部工作**
  - **`requests.get()`（模块级函数模式）**：在函数内部，会构造一个 `Request` 对象，通过 `Session` 发送它，然后组装返回 `Response` 对象。
  - **`pymysql.connect()`（工厂函数模式）**：在函数内部，处理网络连接、协议握手等，最终初始化并返回一个可用的 `Connection` 对象。
- **直观性**
  - **`requests.get()`（模块级函数模式）**：**更高**。`requests.get(url)` 几乎像一句自然语言："请求，获取（某网址）"。
  - **`pymysql.connect()`（工厂函数模式）**：清晰。"PyMySQL，连接（到某数据库）"。

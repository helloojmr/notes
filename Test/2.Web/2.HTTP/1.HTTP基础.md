## HTTP 协议

### HTTP 定义
- 超文本传输协议，基于请求与响应的应用层协议

### Http 请求
-  格式
	- 请求行：**请求方法** **url** **协议/协议版本号**
	- 请求头：**key:value**（客户端的属性信息）
		- Content-Type：指定请求体数据类型
		- **application/json：JSON格式**
		- **application/x-www-form-urlencoded：表单默认的提交数据格式**
		- text/html：HTML格式
		- text/plain：纯文本格式
		- image/jpeg：jpg图片格式
	- 空行：标识请求头结束
	- 请求体：**请求携带的数据**
		- 有些请求没有请求体，如get、delete
		- 请求体的数据类型受请求头的Content-Type控制
- **请求方法**
  - **GET（查询）**
    - 无请求体
    - url携带参数，长度有限制
    - 例如：搜索
  - **POST（添加）**
    - 请求参数在请求体中
    - 请求体长度无限制，可以传递任意数量的参数
    - 例如：登录、注册
  - **DELETE（删除）**
    - 无请求体
  - **PUT（修改）**
- **url（网址）**
  - 统一资源定位符，网络资源地址。
  - 格式：**协议(http、https、ftp等)://主机地址（域名或IP）:端口号/资源路径?查询参数1&查询参数2**
  - 示例：https://www.itcast.cn:8080/news/index.html?uid=123&page=1
    - 端口号省略，跟随协议。**http-80 https-443**
    - 资源路径省略。资源路径为**/**
    - 查询参数：key1=value1&key2=value2


### Http 响应

- 响应行：协议/协议版本号 响应状态码 响应状态描述
- **响应状态码**
  - **2xx**：成功
  - **3xx**：重定向
  - **4xx**：客户端错误
  - **5xx**：服务端错误
- 响应头：name:value 服务端的属性信息
- 响应体：html/json/txt

## 抓包

- 说明：客户端向服务器发送请求以及服务器响应客户端的请求，都是以数据包来传递的
- 抓包(packet capture)：通过工具拦截客户端与服务器交互的数据包
- **为什么要抓包？**
  - 定位是前端还是后端问题
    - 抓不到请求，前端问题
    - 有请求无响应，后端问题
    - 有请求有响应，分析响应信息
  - 弱网测试
  - 直接发送请求测试服务端
- **怎么抓包？**
  - Fiddler
  一个http协议调试**代理**工具，记录并检查电脑与互联网之间的http/https通讯
    - filters设置
    - inspectors(raw)
    - 弱网设置（Rules --> Performance --> Simulate Modem Speeds）
    - 设置断点breakpoint（before requests/after responses）
  - F12抓包
- 设置防止篡改数据的策略

## RPC

- 远程过程调用
- 常见的 RPC 框架有 Dubbo、Thrift、gRPC

## Dubbo

- Dubbo 是一款高性能、轻量级、基于 Java 的开源 RPC（Remote Procedure Call）框架
- Dubbo 接口的作用：远程调用 Java 方法，传参、获取返回值

## Api 文档解析

- 服务名、方法名、参数类型、返回值类型

## Python 借助 Dubbo 远程调用

### dubboclient

#### 定义

##### 说明
- 基于 telnetlib 类库封装的，用于测试 dubbo 接口的客户端工具类
- 说明：
  - telnetlib 是 Python 内置的模块，用于创建 Telnet 协议的连接。
  - telnetlib 模块提供一个实现 Telnet 协议的类 Telnet，通过该类可以模拟调用 dubbo 接口。

#### 实现：传递普通参数
```
案例一：传递普通参数
from dubboclient import DubboClient
# 创建DubboClient对象
dubbo_client = DubboClient("211.103.136.244", 6502)
# 调用服务接口
# Member findByTelephone(String telephone)
resp = dubbo_client.invoke("MemberService", "findByTelephone", "13020210001")
# 获取响应数据
print("response=", resp)
print(type(resp))
# String {"fileNumber":"D0803","id":3,"idCard":"210102199003073415","name":"李白","phoneNumber":"13028210001","regTime":1623427200000,"sex":"1"}
# <class 'str'>
```

#### 实现：传递自定义类参数
```
案例二：传递自定义类参数
# 自定义类的传参格式，使用列表形式组织参数，添加 "class":类 键值对
info = {"id": 911, "name": "杜甫", "phoneNumber": "13048379884"}
info["class"] = "com.itheima.pojo.Member"
# void add(Member)
resp = dubbo_client.invoke("MemberService", "add", info)
```

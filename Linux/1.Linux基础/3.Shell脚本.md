## Shell 脚本基础

### 脚本结构
- **shebang**：脚本第一行 `#!/bin/bash`，指定解释器
- **执行方式**：
  - `bash script.sh`（无需执行权限）
  - `./script.sh`（需先 `chmod +x script.sh`）
#### 示例
```
#!/bin/bash
# 第一个脚本
echo "Hello, Test!"
```

### 变量
- **自定义变量**：`name="value"`（等号两侧不能有空格）
- **使用变量**：`$name` 或 `${name}`
- **环境变量**：`export name="value"`，子进程可继承
- **特殊变量**：
  - `$0`：脚本名
  - `$1 ~ $9`：第 1~9 个位置参数
  - `$#`：参数个数
  - `$?`：上一条命令的退出码（0 表示成功）
  - `$@`：所有参数
#### 示例
```
#!/bin/bash
name="test"
echo "脚本名: $0, 参数个数: $#, 第一个参数: $1"
```

### 输入输出
- **echo**：输出，`echo -e` 支持转义
- **read**：读取输入，`read -p "请输入: " var`
#### 示例
```
#!/bin/bash
read -p "请输入测试环境地址: " env
echo "开始部署到: $env"
```

### 运算符
- **算术运算**：`$((1 + 2))` 或 `expr 1 + 2`（expr 中运算符两侧必须有空格）
- **数字比较**：`-eq`（等于）`-ne`（不等）`-gt`（大于）`-ge`（大于等于）`-lt`（小于）`-le`（小于等于）
- **字符串比较**：`=`（等于）`!=`（不等）`-z`（为空）`-n`（非空）
- **文件判断**：`-f`（是文件）`-d`（是目录）`-e`（存在）`-x`（可执行）`-w`（可写）`-r`（可读）

## 条件判断与循环

### 分支结构

#### if 分支
```
#!/bin/bash
if [ -f /etc/nginx/nginx.conf ]; then
    echo "配置文件存在"
elif [ -d /etc/nginx ]; then
    echo "目录存在但缺少配置文件"
else
    echo "nginx 未安装"
fi
```

#### case 分支
```
#!/bin/bash
case $1 in
    start)
        echo "启动服务";;
    stop)
        echo "停止服务";;
    restart)
        echo "重启服务";;
    *)
        echo "用法: $0 start|stop|restart";;
esac
```

### 循环结构

#### for 循环
```
#!/bin/bash
# 遍历列表
for env in dev test prod; do
    echo "部署到 $env 环境"
done

# C 风格
for ((i = 1; i <= 5; i++)); do
    echo "第 $i 次执行"
done

# 遍历文件
for f in /var/log/myapp/*.log; do
    echo "处理日志: $f"
done
```

#### while 循环
```
#!/bin/bash
# 计数器
count=1
while [ $count -le 5 ]; do
    echo "循环第 $count 次"
    count=$((count + 1))
done

# 按行读取文件
while read line; do
    echo "读取到: $line"
done < app.log
```

#### 循环控制
- **break**：跳出整个循环
- **continue**：跳过本次循环，继续下一次

## 函数

```
#!/bin/bash
# 定义函数
function check_service() {
    local name=$1   # local 声明局部变量
    systemctl status $name > /dev/null 2>&1
    return $?       # 返回值: 0 正常, 非0 异常
}

# 调用函数
if check_service nginx; then
    echo "nginx 运行正常"
else
    echo "nginx 异常，尝试重启"
    systemctl start nginx
fi
```

## 定时任务（crontab）

- **格式**：分 时 日 月 周 命令
- 常用示例：
  - `*/5 * * * * /path/check.sh`：每 5 分钟执行
  - `0 2 * * * /path/clean.sh`：每天凌晨 2 点执行
  - `0 0 * * 0 /path/backup.sh`：每周日零点执行
- **管理命令**：`crontab -l` 查看，`crontab -e` 编辑
- **实战要点**：定时清理日志、定时跑回归测试、定时监控告警

## 实战脚本

### 脚本案例

#### 日志自动清理脚本
```
#!/bin/bash
# 清理7天前的日志
LOG_DIR="/var/log/myapp"
find $LOG_DIR -name "*.log" -mtime +7 -exec rm -f {} \;
# 也可以压缩后保留
find $LOG_DIR -name "*.log" -mtime +7 -exec gzip {} \;
```

#### 服务健康检查脚本
```
#!/bin/bash
# 检查服务是否存活，不存活则重启
SERVICE="nginx"
if ! pgrep -x "$SERVICE" > /dev/null; then
    echo "$(date) $SERVICE is down, restarting..." >> /var/log/service_monitor.log
    systemctl start $SERVICE
    # 发送告警
    curl -X POST http://monitor/api/alert -d "service=$SERVICE down"
fi

# 配合 crontab 定时执行
# */5 * * * * /path/to/check.sh
```

#### 测试数据准备脚本
```
#!/bin/bash
# 向数据库批量插入测试用户
for i in {1..100}
do
    mysql -utest -p123456 testdb -e "INSERT INTO users (name, email) VALUES ('testuser$i', 'user$i@test.com');"

```

#### 接口压测脚本（结合 curl）
```
#!/bin/bash
# 并发请求接口
for i in {1..10}; do
    curl -s -o /dev/null -w "Request $i: %{http_code}\n" http://localhost:8080/api/test &
done
wait
```

#### 批量部署脚本
```
#!/bin/bash
# 批量部署到多台服务器
SERVERS="192.168.1.10 192.168.1.11 192.168.1.12"
for ip in $SERVERS; do
    scp app.tar.gz root@$ip:/opt/
    ssh root@$ip "cd /opt && tar -zxvf app.tar.gz && systemctl restart myapp"
    echo "$ip 部署完成"
done
```

#### 数据库备份脚本
```
#!/bin/bash
# 备份数据库到带日期的文件，保留7天
BACKUP_DIR=/backup/mysql
mkdir -p $BACKUP_DIR
mysqldump -uroot -p123456 testdb > $BACKUP_DIR/testdb_$(date +%Y%m%d).sql
# 删除7天前的备份
find $BACKUP_DIR -name "*.sql" -mtime +7 -exec rm -f {} \;
```

#### 日志分析统计脚本
```
#!/bin/bash
# 统计错误类型 Top10
grep "ERROR" /var/log/myapp/app.log | \
    awk '{print $NF}' | sort | uniq -c | sort -nr | head -10
# 统计某接口的调用次数
grep "/api/order" access.log | wc -l
```

## 面试高频题

- **Q**：`$?` 表示什么？**A**：上一条命令的退出码，0 表示成功，非 0 表示失败。脚本中常用它判断命令是否执行成功。
- **Q**：如何给脚本传参？**A**：`$1~$9` 取位置参数，`$#` 取参数个数，`$@` 取所有参数；脚本名用 `$0`。
- **Q**：数字比较和字符串比较有什么区别？**A**：数字用 `-eq`/`-ne`/`-gt`/`-lt` 等，字符串用 `=`/`!=`/`-z`；混用会导致判断错误。
- **Q**：如何定时执行脚本？**A**：crontab，格式为「分 时 日 月 周 命令」，如 `0 2 * * *` 表示每天凌晨 2 点。
- **Q**：脚本里的明文密码怎么处理？**A**：配置文件单独存放并设置 600 权限、使用环境变量、或对接密钥管理服务，避免密码硬编码在脚本里。
- **Q**：while read line 和 for 遍历文件有什么区别？**A**：while read 按行读取（可处理含空格的整行），for 默认按空格/换行分隔，处理带空格的文件名时容易出错。

## 测试应用场景

- **ls/cd**：查看测试环境目录结构，定位日志、配置文件位置
- **mkdir/rm**：管理测试数据目录，清理临时文件
- **mv/cp**：备份配置文件，部署测试版本
- **cat/more/grep**：查看日志、分析问题、统计错误
- **重定向/管道**：核心技能，将各种命令组合起来，实现自动化数据处理

## 查看目录内容（ls）

### 命令格式与选项
- `ls [-lah] [文件或目录]`

- **-l**：以列表方式详细显示内容信息，包括权限、所有者、大小等
- **-a**：显示所有文件（包含以"."开头的隐藏文件）
- **-h**：人性化显示文件大小（自动转换为 KB/MB 等单位），必须与 -l 配合使用
  - 示例：`ls -lh /usr/bin` 查看 /usr/bin 文件夹内的内容
- **-t**：按时间排序
  - 测开：找最新修改的日志文件：`ls -lt /var/log`
- **-S**：按大小排序
  - 测开：找最大的日志文件：`ls -lS /var/log`
- **-r**：反向排序
  - 测开：配合 -t 使用：`ls -ltr` 看最新修改的在最后
- **-d**：只显示目录
  - 测开：`ls -d */` 只显示当前目录下的文件夹

### 扩展
- 新建文件（不是文件夹）：`touch test.txt`（如果该文件已存在，则更新其时间戳）
- 通配符（以 `touch 123.txt 23.txt abc.txt ab.txt a.txt` 为例）：
  - `ls *.txt`：匹配 0 到多个任意字符
  - `ls ?.txt`：匹配单个任意字符
  - `ls [abcd].txt`：匹配括号内 abcd 中的任意一个字符
  - `ls [a-z].txt`：匹配从 a-z 范围内的任意一个字符
- **查找所有 .log 文件并按时间排序**：`ls -lt *.log`
- **查找文件名包含数字的文件**：`ls *[0-9]*`
- **查找文件名以 a 或 b 开头的 .txt 文件**：`ls [ab]*.txt`
- **排除某种文件**（需先开启扩展通配符 `shopt -s extglob`）：`ls !(*.log)` 显示所有非 .log 文件

### 练习
- 查看当前目录下所有的文件信息，包含隐藏文件：`ls -a`
- 查看根目录下所有的文件信息，并以列表的方式详细列出对应文件的大小：`ls -lh`
- 查看 /bin 目录下的所有 .sh 结尾的文件：`ls /bin/*.sh`

## 切换目录（cd）

### 命令与路径
- 命令格式：`cd [目录名称]`
- **cd . / cd ./**：当前目录
- **cd ..**：切换到上一级目录
- **cd -**：切换到上一次目录
- **cd ~**：回到家目录
- **pushd /var/log / popd**：入栈切换 / 回到原目录
- **绝对路径**：唯一路径，/ 开头，~ 开头（~ 就是 /home/用户名/）
- **相对路径**：从当前目录出发，如 `cd home` 和 `cd /home`

### 练习
- 以绝对路径的方式切换到 /etc/kernel 目录下：`cd /etc/kernel`
- 以相对路径的方式切换到 /home 目录下：`cd /`; `cd home`
- 以相对路径的方式切换到 /usr/local 目录下：`cd /`; `cd usr`; `cd local`

- **Q**：什么时候用绝对路径，什么时候用相对路径？**A**：脚本中用绝对路径，确保无论从哪执行都能找到文件（如 `/home/test/logs/app.log`）；手工操作时用相对路径，方便快捷（如 `cd ../conf`）。

## 创建文件夹（mkdir）
### 命令与选项

- 命令格式：`mkdir 目录名称`
- **-p**：实现多个层级的目录创建，如 `mkdir -p dir1/dir2/dir3`
- 如果创建的目录名称已存在，则创建失败
- **创建带权限的目录**：`mkdir -m 755 test_dir`
- **创建多个平级目录**：`mkdir dir1 dir2 dir3`
- **创建带日期的目录**（自动化脚本常用）：`mkdir backup_$(date +%Y%m%d)`

### 测开应用
- 每次运行测试前，创建独立的日志目录：`mkdir -p test_run_$(date +%Y%m%d_%H%M%S)/logs`
- 测试完成后，将日志移入：`mv *.log test_run_*/logs/`

## 删除文件或目录（rm）
### 命令与安全删除

- 命令格式：`rm [-ifr] 目录名或文件名`
- **-r**：表示文件夹及文件夹下所有的内容
- **-f**：表示强制删除，忽略不存在的文件
- **-i**：表示交互式删除
- **删除前先确认**：`ls -la` 先看清楚要删什么；`rm -i file.txt` 交互式确认
- **删除目录前先查看大小**：`du -sh dir_to_delete`
- **安全删除**：先移动到临时目录，确认无误后再清空
  - `mkdir -p /tmp/trash`
  - `mv dangerous_dir /tmp/trash/`
  - `rm -rf /tmp/trash/*`

### 测开应用
- 删除 7 天前的临时文件：`find /tmp/test_data -type f -mtime +7 -exec rm -f {} \;`

## 移动与拷贝（mv / cp）

### cp 高级选项
- **-a**：归档模式，保留所有属性
  - 测开：备份配置文件：`cp -a /etc/nginx/nginx.conf ./backup/`
- **-u**：只复制更新的文件
  - 测开：增量部署：`cp -u dist/* /var/www/html/`
- **-p**：保留属性（所有者、时间）
  - 测开：`cp -p file1 file2`
- **-r**：递归复制目录
  - 测开：`cp -r test_dir/ backup/`

### mv 选项与注意事项
- 命令格式：`mv 源文件 目标文件`
- **-f**：强制覆盖已存在的目标文件而不提示
- **-i**：交互式
- **-v**：显示移动的进度
- **-r**：表示文件夹及文件夹下所有的内容

- **移动并重命名**：`mv old_name.txt new_name.txt`
- **移动多个文件到目录**：`mv file1.txt file2.txt dir/`
- **注意**：如果目标目录不存在，mv 会重命名文件而不是移动到目录，所以先确保目标目录存在

### 练习
- 将 /etc/hosts 文件复制到 /opt 目录下：`sudo cp /etc/hosts /opt`
- 将 /etc/hosts 文件移动到 /opt 目录下：`sudo mv /etc/hosts /opt`

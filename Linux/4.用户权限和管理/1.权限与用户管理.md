## 测试中常见权限问题

- **服务启动失败**
  - 权限问题表现：提示 "Permission denied"
  - 检查二进制文件是否有执行权限，配置文件是否可读
- **日志无法写入**
  - 权限问题表现：应用无报错但日志为空
  - 检查日志目录的写权限，查看属主是否正确
- **脚本执行失败**
  - 权限问题表现：`./script.sh` 提示权限不够
  - 添加执行权限 `chmod +x script.sh`
- **文件上传失败**
  - 权限问题表现：Web 应用无法保存文件
  - 检查上传目录的写权限，考虑属主是否为 web 用户
- **多用户协作**
  - 权限问题表现：A 用户创建的文件 B 无法修改
  - 理解属主/属组关系，设置合适权限或使用 ACL

- **Q**：你在测试环境中遇到过哪些权限问题？怎么解决的？**A**：有一次部署服务时，启动脚本报错 "Permission denied"，我用 `ls -l` 查看发现文件没有执行权限，用 `chmod +x` 解决。还有一次应用日志写不进去，发现日志目录属主是 root，而应用以普通用户运行，我用 `chown` 修改属主后解决。

## 权限基础

### 权限位的完整格式

- `-rwxr-xr--  1 user group  1024 Mar 16 10:00 filename`
- **第1位**：文件类型
  - `-`：普通文件
  - `d`：目录
  - `l`：符号链接
  - `c`：字符设备
  - `b`：块设备
  - `s`：套接字
  - `p`：管道
- **第2-4位**：文件所有者（user）的权限
- **第5-7位**：文件所属组（group）的权限
- **第8-10位**：其他用户（others）的权限
- **第11位**：如果开启了 ACL 或 SELinux 上下文，可能会显示 `.` 或 `+`

### 权限数值

- r 读 4，w 写 2，x 执行 1，- 无权限 0
- 777 = rwxrwxrwx
- 755 = rwxr-xr-x（常见目录/可执行文件）
- 644 = rw-r--r--（常见普通文件）
- 600 = rw-------（私密文件）

### 目录权限的特殊性

- 目录的权限含义与文件不同：
  - **r**：允许列出目录内容（ls）
  - **w**：允许在目录中创建/删除文件（即使对文件无写权限）
  - **x**：允许进入目录（cd），是访问目录下文件的**前提**（必须有 x 才能读取文件内容）
- **常见误区**：对目录只有 r 权限而无 x，可以 ls 但无法 cd 进入，也无法读取目录内文件的元数据。

### 特殊权限位（SUID / SGID / Sticky）

- 除了 rwx，还有三个特殊权限：
  - **SUID**
    - 数值：4
    - 作用：当文件被执行时，进程拥有文件所有者的权限
    - 示例：`chmod 4755 file`（如 `/usr/bin/passwd`）
  - **SGID**
    - 数值：2
    - 作用：文件：执行时获得文件所属组的权限；目录：在该目录下新建文件继承目录的组
    - 示例：`chmod 2755 dir`
  - **Sticky**
    - 数值：1
    - 作用：目录下文件只能被所有者删除（如 `/tmp`）
    - 示例：`chmod 1777 dir`
- SUID 常见于需要临时提升权限的程序（如 `passwd` 修改密码）
- SGID 常用于共享目录，使组内成员新建的文件自动属于同一组
- Sticky 位用于临时目录，防止用户删除他人文件

## chmod 权限修改

### 字母法
- 格式：`chmod u+x 文件名`
- **用户对象**：u（所有者）g（属组）o（其他）a（all 所有）
- **操作符**：+（添加）-（移除）=（设置）
- **权限**：r（读）w（写）x（执行）
- **为所有者添加执行权限，移除其他人的读权限**：`chmod u+x,o-r file`
- **为所有用户（a）添加读权限**：`chmod a+r file`
- **递归修改目录及其内部所有文件**：`chmod -R 755 directory/`

### 数字法
- 权重：rwx = 421 → 777
- 示例：`chmod 765 1.txt`（rwxrw-r-x）
- **设置常见权限**：`chmod 644 file`（-rw-r--r--）、`chmod 755 script`（-rwxr-xr-x）、`chmod 700 private`（-rwx------）
- **带特殊权限的数字法（4 位）**：`chmod 4755 file`（SUID）、`chmod 2755 dir`（SGID）、`chmod 1777 dir`（Sticky）
- **将 file2 的权限设置为与 file1 相同**：`chmod --reference=file1 file2`

### 修复权限
- **给脚本添加执行权限**：`chmod +x deploy.sh`
- **确保 Web 目录可被 nginx 用户读取**：`chown -R nginx:nginx /var/www/html`; `chmod -R 755 /var/www/html`
- 组合示例：`touch 123.txt && chmod 777 123.txt`

## 用户管理

### 常用命令

#### 新增用户
- 新增用户：`useradd 用户名`
  - `useradd -g root admin`：创建 root 组用户 admin

#### 删除用户
- 删除用户：`userdel -r 用户名`
  - `-r` 作用为删除用户目录

#### 切换用户
- 切换用户：`su -` 或者 `su 用户名`
  - `su -` 切换到 root 用户

#### 修改密码
- 更改密码：`passwd`

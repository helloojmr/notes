## 查看文件头部/尾部（head / tail）

- **显示前 20 行（默认 10 行）**：`head -n 20 filename`
- **显示前 100 个字节**：`head -c 100 filename`
- **显示最后 20 行**：`tail -n 20 filename`
- **实时跟踪文件新增内容（常用）**：`tail -f filename`
- **显示最后 20 行并跟踪**：`tail -20f filename`
- **实时监控错误**：`tail -f filename | grep ERROR`
- **tail -f 与 --pid 结合**：当进程结束时自动退出 `tail -f --pid=<PID> filename`
- **多个文件同时监控**：`tail -f file1 file2`
- 使用 `less +F` 实现类似 `tail -f`，且支持搜索
- **实时监控日志并触发动作**：`tail -f app.log | grep --line-buffered "ERROR" | while read line; do echo "$(date): $line" >> error_alerts.log; curl -X POST http://alert/api -d "msg=$line"; done`

- **Q**：如何查看一个超大文件（如 10GB）的最后 100 行？**A**：直接 `tail -n 100 hugefile`，tail 只读取文件末尾，不会加载整个文件，效率很高。同理，`head -n 100` 也只读取开头。

## 组合命令实战

### 场景1：服务启动失败排查
- **检查端口是否被占用**：`sudo netstat -lnpt | grep 8080`（或 `sudo lsof -i:8080`）
- **查看进程是否存在**：`ps -ef | grep myapp`
- **实时查看日志**：`tail -f /var/log/myapp/error.log`
- **查看系统资源**：`top -b -n 1 | head -20`; `free -h`; `df -h`

### 场景2：找出占用CPU最高的Java线程
- **找到 Java 进程 PID**：`ps -ef | grep java`
- **top 查看该进程内线程**：`top -H -p <PID>`
- **记录高 CPU 线程 TID，转 16 进制**：`printf "%x\n" <TID>`
- **用 jstack 查看线程堆栈**：`jstack <PID> | grep -A20 <16进制TID>`

### 场景3：清理僵死进程
- **查找僵死进程（状态 Z）**：`ps aux | awk '$8=="Z" {print $2}'`
- **如果无法 kill，尝试 kill 父进程**：`ps -o ppid= -p <PID>` 获取父 PID，再 `kill -9 <父PID>`

### 场景4：实时统计接口错误率
- **实时统计接口错误率**：`tail -f access.log | awk '/api\/order/ {if($9>=500) err++; else total++} END{print "错误率:", err/(err+total)*100"%"}'`

## 系统整体状况（vmstat）

- **每秒输出一次，共 10 次**：`vmstat 1 10`
- 关注列
  - **r**：运行队列（CPU 负载）
  - **b**：不可中断睡眠进程（I/O 等待）
  - **si/so**：swap in/out（内存紧张）

## 磁盘 I/O（iostat）

- **每秒显示扩展统计**：`iostat -x 1`
- 关注列
  - **%util**：磁盘利用率
  - **await**：平均 I/O 等待时间

## 内核日志（dmesg）

- **查看最近内核消息**：`dmesg | tail -20`
- **应用**：查看硬件错误、OOM killer 信息、驱动问题。

## 网络工具（nc / netcat）

- **测试端口是否开放**：`nc -zv 192.168.1.100 8080`
- **传输文件**：接收端 `nc -l 1234 > received.txt`，发送端 `nc 192.168.1.101 1234 < send.txt`

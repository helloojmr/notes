## 网络状态查看（netstat）
### 查看命令

- 查看系统监听端口：查看当前系统网络状态及对应软件使用的端口号及进程号，root 用户操作
- 命令格式：`netstat [-anptu] | grep '关键字'`
- 常用示例：`netstat -anp | grep mysql`
- 选项说明：
  - **-a**：显示所有连接和监听端口
  - **-n**：不解析主机名，直接显示 IP
  - **-p**：显示进程 PID 和名称
  - **-t**：TCP 协议
  - **-u**：UDP 协议
  - **-l**：只显示监听端口
- **查看所有监听端口及对应进程（root）**：`netstat -lnpt`
- **查看某个端口是否被占用**：`netstat -anp | grep :8080`
- **统计各状态连接数**：`netstat -n | awk '/^tcp/ {++S[$NF]} END {for(a in S) print a, S[a]}'`
- **排查端口冲突**：启动服务时提示端口被占用，用 `lsof -i:8080`（或 `netstat -anp | grep 8080`）找到 PID 后 `kill -9 <PID>`

### 现代替代：ss
- `ss` 是 `netstat` 的替代品，速度更快，推荐使用
- **查看端口**：`ss -lnpt | grep :8080`
- **显示统计信息**：`ss -s`

- **Q**：`netstat` 中 `TIME_WAIT` 状态过多怎么办？**A**：`TIME_WAIT` 是主动关闭连接的一方等待 2MSL 时间，属于正常状态。如果过多，可能导致端口耗尽。可在服务端优化：开启 `tcp_tw_reuse` 和 `tcp_tw_recycle`（需谨慎），或调整长连接策略。

## 列出打开文件（lsof）

- **-i**：表示查看所有已打开的进程的端口
- **lsof -i:3306**：查看系统中 3306 的端口是否已打开
- **lsof -p 1234**：查看进程 1234 打开的文件
- **lsof /var/log/messages**：查看谁正在使用该文件
- **使用场景**：看看我们要用的端口被哪个进程占用了，然后 kill 掉它
- **lsof -u username**：查看用户打开的文件
- **lsof +D /path**：递归查看目录下被打开的文件
- **lsof -c nginx**：查看 nginx 进程打开的文件
- **无法卸载磁盘**（umount 提示 device is busy）：`lsof /mnt/data` 找出正在使用该目录的进程，kill 掉后卸载

- **Q**：`netstat` 和 `lsof -i` 有什么区别？**A**：`netstat` 专注于网络连接和端口，`lsof -i` 更通用，可以列出所有网络文件，同时还能查看其他类型的文件。

## 网络抓包（tcpdump）

- **抓取 80 端口的包，保存到文件**：`sudo tcpdump -i eth0 port 80 -w capture.pcap`
- **抓取并直接分析**：`sudo tcpdump -i eth0 -A 'tcp and port 8080'`
- **应用**：排查网络问题，查看请求/响应内容，验证加密等。

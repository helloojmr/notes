## 三种模式

- **命令行模式**（正常模式）
  - 作用：移动光标、复制粘贴、删除等操作
  - 进入方式：启动 vim 默认进入；从其他模式按 `Esc` 返回
- **插入模式**
  - 作用：输入文本
  - 进入方式：`i`（光标前插入）、`I`（行首）、`a`（光标后）、`A`（行尾）、`o`（下行开新行）、`O`（上行开新行）
- **末行模式**（底行模式）
  - 作用：保存退出、查找替换、设置参数
  - 进入方式：在命令行模式按 `:` 进入
  - 常用命令：
    - `w`：保存文件并回到命令行模式
    - `q`：退出 vim
    - `!`：强制
    - `wq!`：强制保存并退出

## 常用快捷键（命令行模式）

- **复制当前行**：`yy`
- **粘贴**：`p`（粘贴到光标后）、`P`（粘贴到光标前）
- **剪切/删除当前行**：`dd`
- **删除单个字符**：`x`（光标后）、`X`（光标前）
- **撤销**：`u`
- **反撤销**：`Ctrl + r`
- **跳转到文件开头**：`gg`
- **跳转到文件结尾**：`G`
- **跳转到指定行**：`:行号`（末行模式）或 `行号G`
- **搜索**：`/keyword` 向下搜索，`?keyword` 向上搜索，`n` 下一个，`N` 上一个
- **替换当前行第一个匹配**：`:s/old/new/`
- **替换全文所有匹配**：`:%s/old/new/g`
- **显示行号**：`:set nu`（临时），`set nonu` 取消
- **保存并退出**：`ZZ`（大写，相当于 `:wq`）

## 实战技巧

### 快速编辑配置文件
```
vim /etc/nginx/nginx.conf
# 常用操作：/listen 查找，dd删除行，yy复制行，p粘贴，:wq保存
```

### 多文件编辑
```
vim file1 file2
:next    # 切换到下一个文件
:prev    # 切换到上一个文件
:first   # 第一个文件
:last    # 最后一个文件
```

### 分屏编辑
```
vim -o file1 file2   # 水平分屏
vim -O file1 file2   # 垂直分屏
# 在vim内分屏：:sp file2（水平）, :vsp file2（垂直）
# 切换分屏：Ctrl+w 然后按方向键或 Ctrl+w w
```

#### 永久行号设置
- **设置永久行号**：在 `~/.vimrc` 中添加 `set nu`。

## 面试题

- **Q**：如何快速删除从当前行到文件末尾的所有内容？**A**：在命令行模式输入 `dG`（d 表示删除，G 表示到文件尾）。
- **Q**：如何将文件中的 `foo` 全部替换为 `bar`，但需要逐个确认？**A**：`:%s/foo/bar/gc`（c 表示 confirm）。
- **Q**：如何同时编辑多个文件并复制粘贴内容？**A**：用 `:sp` 分屏，或 `:next` 切换文件，用 `yy` 复制，然后 `p` 粘贴到另一个文件。

## 练习

- 把 /bin 目录下的所有内容的详细信息重定向到文件 info 中：`ls -al /bin >> info`
- 把 /bin 目录下的所有内容的详细信息分屏显示：`ls -al /bin | more`
- Windows 和 Linux 下获取 IP 地址命令：ipconfig / ifconfig
- 查看所有用户的进程：`ps -aux`
- 在桌面新建 test 文件夹，并建立 1.txt 2.txt 3.txt 4.txt 文件，打包：`mkdir ~/Desktop/test && touch ~/Desktop/test 1.txt 2.txt 3.txt 4.txt && tar -zcvf test.tar.gz ~/Desktop/test`
- 将 test.tar.gz 解压到 /home/admin/文档 目录下：`tar -zxvf test.tar.gz -C /home/admin/文档`
- 修改 test 文件下所有 txt 文件权限：`chmod 531 *.txt`
- 查看 3306 端口是否被占用：`netstat -anop | grep 3306`; `lsof -i:3306`

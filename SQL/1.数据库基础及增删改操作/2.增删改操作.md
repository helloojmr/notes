## 创建表

### 建表语法
```
create table [IF NOT EXISTS] 表名（
    字段名1 类型 约束 [COMMENT '注释']，
    字段名2 类型 约束
    ...
）ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='表注释';

create table students(
    id int unsigned primary key auto_increment comment'主键',
    name varchar(20) NOT NULL comment'姓名',
    age int unsigned,
    height decimal(5,2),
    status TINYINT DEFAULT 1 COMMENT '状态 1:有效 0:无效',
    create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间'
);
```
### 关键点说明
- `ENGINE=InnoDB`：支持事务和外键，是默认引擎。
- `AUTO_INCREMENT`：自增字段，插入时可用 0 或 NULL，系统会自动分配。
- `CURRENT_TIMESTAMP`：自动记录当前时间，`ON UPDATE` 可在更新时自动刷新。
- **Q**：InnoDB 和 MyISAM 有什么区别？**A**：InnoDB 支持事务、外键、行级锁，适合写操作多的场景；MyISAM 不支持事务，表级锁，适合读多写少的场景。现在 MySQL 默认使用 InnoDB。

## 删除表

- **删除表**（数据+结构）：`drop table students;`
- **安全删除**（先判断存在）：`drop table if exists students;`

## 数据插入
### 全字段插入

#### 说明
- **全字段插入**（必须按顺序，自增主键可用 0 或 NULL 代替，系统自动生成）：
#### 示例
```
insert into students values(0,'pitt',22,172.33);
```
### 指定字段插入

#### 说明
- **指定字段插入**（推荐，可读性强，未指定字段使用默认值或 NULL）：
#### 示例
```
insert into students (name,age) values ('pitt',14);
```
### 插入多行
#### 示例
```
insert into students values (0,'jiang',32,189.22),(0,'ming',32,182.32);
insert into students (name,age) values('jiang',22),('ming',32);
```
### 插入注意事项
- 插入时要注意约束：主键重复会报错，NOT NULL 字段必须给值，UNIQUE 字段不能重复。
- 日期字段可用字符串格式 `'2025-03-17 10:00:00'`，MySQL 会自动转换。

## 数据更新

### UPDATE 语法
#### 语法结构
```
update 表名
set 字段名1=值1,字段名2=值2
where 条件;
```
#### 示例

#### 说明
- 示例：修改 id 为 5 的学生数据，姓名改为狄仁杰，年龄改为 20：
#### 示例代码
```
update students
set name='狄仁杰',age=20
where id = 5;
```
### 更新注意事项
- **永远记得加 WHERE 条件**，否则全表更新。
- 更新操作可能影响多行，可用 `ROW_COUNT()` 函数获取影响行数，便于断言。
- **扩展**：更新时可以使用字段原有值，如 `SET age = age + 1`。

## 数据删除
### 删除方式

#### 说明
- **DELETE**：删除符合条件的行，不加 WHERE 会删除所有行（但速度慢，逐行删除）：`delete from 表名 where id=6;`
- **TRUNCATE**：清除表中所有数据，保留表结构，自增主键重置为 1（比 DELETE 快）：`truncate table 表名;`
- **DROP**：连表结构一起删除：`drop table 表名;`
- 此删除为物理删除，逻辑删除是设置一个字段标识是否删除，如 `is_delete`：
### 逻辑删除
#### 示例
```
-- 添加逻辑删除字段
ALTER TABLE students ADD COLUMN is_delete TINYINT DEFAULT 0 COMMENT '0未删除 1已删除';

-- 逻辑删除操作（用UPDATE代替DELETE）
UPDATE students SET is_delete = 1 WHERE id = 5;

-- 查询时自动过滤已删除数据
SELECT * FROM students WHERE is_delete = 0;
```
### 删除方式对比
- **Q**：DELETE 和 TRUNCATE 的区别？**A**：DELETE 是 DML，逐行删除，可以加 WHERE 条件，删除后自增计数器不会重置，且可以回滚（如果在一个事务中）。TRUNCATE 是 DDL，直接删除表并重建，速度快，不能加 WHERE，自增重置，无法回滚。

## 事务控制

### 事务语法
```
-- 开启事务
START TRANSACTION;  -- 或 BEGIN;

-- 执行一系列操作（INSERT/UPDATE/DELETE）
INSERT INTO students (name) VALUES ('test');
UPDATE students SET age = 20 WHERE name = 'test';

-- 如果一切正常，提交事务
COMMIT;

-- 如果出错，回滚所有操作
ROLLBACK;
```
### 测试应用
- 在测试用例中，可以在开始前开启事务，结束后回滚，这样数据不会真正写入数据库，无需手动清理。但要注意，事务对 DDL（如 CREATE TABLE）无效。

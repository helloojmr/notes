## 分页（LIMIT）

- 语法：`select * from 表名 limit start,count`（从 start 开始，获取 count 条数据，start 索引从 0 开始）
- 查询前三行学生信息：`select * from students limit 0,3`
- 分页公式：`select * from 表名 limit (n-1)*m,m`（n 代表页数，m 代表每页显示的个数）

- **Q**：如何优化大分页查询？比如 `LIMIT 1000000, 10`？**A**：大分页偏移量大，效率低。可改用子查询先获取起始 ID，再查询：`SELECT * FROM table WHERE id > (SELECT id FROM table ORDER BY id LIMIT 1000000,1) LIMIT 10;`

## 连接查询

### 内连接
- 结果：两个表匹配到的数据（取交集）
- 语法：`select * from 表1 inner join 表2 on 表1.列1=表2.列1`
- 等价写法：`select * from 表1,表2 where 表1.列1=表2.列2`
- 示例：
  - `select * from students stu inner join scores sc on stu.studentNo=sc.studentNo;`
  - `select * from students,scores where students.studentno = scores.studentno;`
  - `select * from courses co inner join scores sc on co.courseno=sc.courseno;`
  - 查询王昭君的成绩，要求显示姓名、课程号、成绩：`select stu.name,sc.courseno,sc.score from students stu inner join scores sc on stu.studentno=sc.studentno where stu.name='王昭君';`
  - 查询学生信息及学生的课程：`select * from students stu inner join scores sc on stu.studentno=sc.studentno inner join courses cou on sc.courseno = cou.courseno;`
  - 查询王昭君数据库课程成绩：`select stu.name,cou.name '课程名',sc.score from students stu inner join scores sc on stu.studentno=sc.studentno inner join courses cou on sc.courseno = cou.courseno where stu.name='王昭君' and cou.name='数据库';`
  - 查询男生中最高成绩，显示姓名、课程号、成绩：`select stu.name,cou.courseno,sc.score from students stu inner join scores sc on stu.studentno=sc.studentno inner join courses cou on sc.courseno = cou.courseno where stu.sex='男' order by sc.score desc limit 0,1;`

### 左连接
- 结果：两个表匹配到的数据 + 左表特有的数据，右表不存在的数据用 null 填充
- 语法：`select * from 表1 left join 表2 on 表1.列1=表2.列1`
- 示例：`select * from students stu left join scores sc on stu.studentno=sc.studentno;`
- 多表：`select * from students stu left join scores sc on stu.studentno=sc.studentno left join courses cs on cs.courseno=sc.courseno`

### 右连接
- 结果：两个表匹配到的数据 + 右表特有的数据，左表不存在的数据用 null 填充
- 语法：`select * from 表1 right join 表2 on 表1.列1=表2.列1`

## 自关联
### 概念

#### 说明
- 自关联：一张表与自己关联，常用于树形结构（省市区、菜单、分类）查询
### 示例
```
-- 创建 areas 表（省市区）
DROP TABLE IF EXISTS areas;
CREATE TABLE areas (
    aid INT PRIMARY KEY,
    attitle VARCHAR(20),
    pid INT
);
-- 插入省市区数据
INSERT INTO areas (aid, attitle, pid) VALUES
('130000', '河北省', NULL),
('130100', '石家庄市', '130000'),
('130400', '邯郸市', '130000'),
('130600', '保定市', '130000'),
('130700', '张家口市', '130000'),
('130800', '承德市', '130000'),
('410000', '河南省', NULL),
('410100', '郑州市', '410000'),
('410300', '洛阳市', '410000'),
('410500', '安阳市', '410000'),
('410700', '新乡市', '410000'),
('410800', '焦作市', '410000'),
('410101', '中原区', '410100'),
('410102', '二七区', '410100'),
('410301', '洛龙区', '410300');

-- 查询市对应的省
select * from areas as a1 inner join areas as a2 on a1.pid=a2.aid;
-- 查询河南省的所有市
select * from areas as a1 inner join areas as a2 on a1.pid=a2.aid where a2.attitle='河南省';
-- 查询区对应的省市区（三级关联）
select * from areas as a1 inner join areas as a2 on a1.pid=a2.aid inner join areas as a3 on a2.pid = a3.aid;
```
### 扩展
- **Q**：如何查询树形结构/无限级分类数据？**A**：可以使用自关联递归查询（MySQL 8.0 支持 CTE 递归），或者多次连接（已知层级数时）。

## 定义
- 代码判断测试执行结果是否符合预期结果的过程
	- **`assertEqual(a, b)`**：a == b
	- **`assertNotEqual(a, b)`**：a != b
	- **`assertTrue(x)`**：x 为 True
	- **`assertFalse(x)`**：x 为 False
	- **`assertIn(a, b)`**：a in b
	- **`assertNotIn(a, b)`**：a not in b
	- **`assertIs(a, b)`**：a is b
	- **`assertIsNot(a, b)`**：a is not b
	- **`assertIsNone(x)`**：x is None
	- **`assertIsNotNone(x)`**：x is not None
	- **`assertIsInstance(a, b)`**：isinstance(a, b)
	- **`assertNotIsInstance(a, b)`**：not isinstance(a, b)
	- **`assertRaises(exception, callable)`**：期望抛出指定异常

- 总是提供 `msg` 参数，让失败信息更明确。
- `self.assertEqual(actual, expected, f"接口返回状态码错误，实际: {actual}")`
- 对复杂数据结构（如字典、列表），可以用 `assertDictEqual`、`assertListEqual`，失败时会显示差异。

## 参数化
### 定义

#### 说明
- 通过参数的方式传递数据，实现数据与脚本分离，unittest本身不支持参数化，但可以通过安装unittest扩展插件**parameterized**实现
### 示例代码
```
from parameterized import parameterized  

data = [(1, 1, 2), (1, 2, 3), (2, 3, 5), (4, 5, 9)]
 
class TestAdd(TestCase):  
	@parameterized.expand(data)  
	def test_add(self, a, b, expected):  
		self.assertEqual(expected, add(a, b))
```

### 接口测试数据驱动
```
# test_login.json
[
    {"username": "valid_user", "password": "123456", "expected": "success"},
    {"username": "invalid_user", "password": "wrong", "expected": "fail"},
    {"username": "", "password": "", "expected": "fail"}
]

# test_login.py
import json
import unittest
import requests
from parameterized import parameterized

def load_login_data():
    with open('test_login.json', 'r', encoding='utf-8') as f:
        return json.load(f)

class TestLogin(unittest.TestCase):
    @parameterized.expand(load_login_data())
    def test_login(self, username, password, expected):
        url = "http://api.example.com/login"
        payload = {"username": username, "password": password}
        response = requests.post(url, json=payload)
        result = response.json().get('status')
        self.assertEqual(expected, result)
```

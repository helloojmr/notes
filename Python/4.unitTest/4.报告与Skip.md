## 生成HTML测试报告
### HTMLTestReport
#### 概述

#### 说明
- unittest不支持生成HTML测试报告，网上有很多类库可以实现，使用HTMLTestReport生成。
#### 示例代码
```
suite = TestSuite()  
suite.addTest(defaultTestLoader.loadTestsFromTestCase(TestAdd))  
with open('./test_report.html', 'wb') as f:
	runner = HTMLTestReport(stream=f, title='测试报告', description='用例执行详情')
runner.run(suite)

# 获取项目绝对路径：BASE_DIR=os.path.dirname(os.path.abspath(__file__))
				 BASE_DIR=os.path.dirname(__file__)
```
### HTMLTestRunner
```
# 需要先下载 HTMLTestRunner.py 放到项目目录
import HTMLTestRunner

suite = unittest.defaultTestLoader.discover('./', pattern='test_*.py')

with open('./report.html', 'wb') as f:
    runner = HTMLTestRunner.HTMLTestRunner(
        stream=f,
        title='测试报告',
        description='执行详情'
    )
    runner.run(suite)
```
## 跳过测试（Skip）
### 常用装饰器

#### 说明
- **`@unittest.skip(reason)`**：无条件跳过
- **`@unittest.skipIf(condition, reason)`**：条件为True时跳过
- **`@unittest.skipUnless(condition, reason)`**：条件为False时跳过
- **`@unittest.expectedFailure`**：标记测试预期失败（用于已知bug）
### 示例代码
```
import unittest

class TestSkip(unittest.TestCase):
    @unittest.skip("直接跳过")
    def test_1(self):
        pass

    @unittest.skipIf(1 < 2, "条件为True，跳过")
    def test_2(self):
        pass

    @unittest.skipUnless(1 > 2, "条件为False，跳过")
    def test_3(self):
        pass

    @unittest.expectedFailure
    def test_4(self):
        self.assertEqual(1, 2)  # 预期失败，不会算作失败
```
### 环境条件跳过

#### 说明
- 根据环境跳过⬇
### 示例代码
```
import os

class TestAPI(unittest.TestCase):
    @unittest.skipIf(os.environ.get('ENV') == 'prod', "生产环境不执行")
    def test_delete_user(self):
        pass        
```

## 测试套件（TestSuite）
### 使用流程
- 实例化套件对象：`unittest.TestSuite()`
- 实例化执行对象：`unittest.TextTestRunner()`
- 执行对象执行套件对象：`执行对象.run(套件对象)`
### 示例代码
```
from unittest import TestCase, TestSuite, TextTestRunner


class TestDemo1(TestCase):  # 继承TestCase类，习惯性以Test开头
    def test_method1_1(self):  # 必须test_开头
        print("测试方法1_1")

    def test_method1_2(self):
        print("测试方法1_2")


class TestDemo2(TestCase):
    def test_method2_1(self):
        print("测试方法2_1")

    def test_method2_2(self):
        print("测试方法2_2")


if __name__ == '__main__':
    suite = TestSuite()
    # 添加用例方法
    # 方法一，添加单个测试方法
    suite.addTest(TestDemo1('test_method1_1'))
    suite.addTest(TestDemo2('test_method2_1'))
    # 方法二，添加整个测试类
    suite.addTests(unittest.TestLoader().loadTestsFromTestCase(TestDemo1))
    # 方法三，使用TestLoader自动发现（最常用）
    suite = TestLoader().discover(test_dir, pattern='test*.py')
    suite = unittest.defaultTestLoader.discover('./', pattern='test_*.py')
    runner = TextTestRunner()  # TTR
    runner.run(suite)
```

## 执行

```
runner = unittest.TextTestRunner(verbosity=2)  # verbosity=2 输出详细日志
runner.run(suite)
```

## Fixture（脚手架）

### 示例代码
```
def setUpModule():
    print("模块级前置：模块开始执行时，只执行一次")

def tearDownModule():
    print("模块级后置：模块执行结束时，只执行一次")

class TestDemo(unittest.TestCase):

    @classmethod
    def setUpClass(cls):
        print("类级前置：类中所有用例执行前，只执行一次")

    @classmethod
    def tearDownClass(cls):
        print("类级后置：类中所有用例执行后，只执行一次")

    def setUp(self):
        print("方法级前置：每条用例执行前执行")

    def tearDown(self):
        print("方法级后置：每条用例执行后执行")

    def test_1(self):
        print("测试方法1")

    def test_2(self):
        print("测试方法2")
```
### 应用场景
- **模块级**：整个测试模块只做一次的操作，如加载配置文件、连接数据库。
- **类级**：同一个测试类共享的资源，如创建浏览器驱动实例（Web 自动化）。
- **方法级**：每条用例独立的数据准备和清理，如插入测试数据、删除测试数据。

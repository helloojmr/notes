## module（模块）与 package（包）
### 模块与包

- 一个 .py 为一个模块，模块中定义的全局变量、类、函数都是提供给外界使用的**工具**
- 将多个 module 放在一个目录下，目录中存在 `__init__.py` 文件，文件可为空
- 导入模块时，会执行模块中的代码
### 模块导入方式
```
import xxx
from xxx import xxx
```
### __name__ 变量
- 解释器会在每个模块自动维护 `__name__` 变量（"身份证"）
  - **模块被直接运行**：`__name__` = `'__main__'`，执行测试或演示代码，当脚本用
  - **模块被导入**：`__name__` = `'模块名'`，只提供函数，不执行测试代码，当模块用
  - `if __name__ == "__main__":` 是 Python 的**标准入口模式**
- 导入模块顺序：优先项目目录，再 Python 系统目录。禁止重名！

## 函数传参的方式
### 传参方式
- 位置传参：按照形参的顺序将实参的值传递给形参
- 关键字传参：在函数调用时，指定将实参传递给哪个形参
- 混合使用：先写位置参数，再写关键字传参；同一个形参不可以通过两种方式传递值
### 传参示例代码
```
def show_info(name, age):
    print(f"name{name},age{age}")

if __name__ == "__main__":
    show_info("小明", 18)
    show_info(age=18, name="小明")
    show_info("小明", age=18)
    show_info(age=18, "小明")  # 报错，positional argument follows keyword argument
```

## 缺省参数
### 缺省参数示例
```
def show_info(name, age=18):
    print(f"name{name},age{age}")

if __name__ == "__main__":
    show_info("小明")
    show_info("小吴", 19)
```
### sort 参数示例
- 示例（sort 的 reverse 参数）：`num_list.sort()` 默认升序；`num_list.sort(reverse=True)` 降序

## 多值参数

### args
#### 打包与解包
- **定义时**：`def func(*args)` → `*` 表示"把传来的多个位置参数打包成元组（args）"
  - 所以定义时的 `*args` 是个动作，表示将接收到的多个形参，组成一个元组，这个元组就是 args
- **调用时**：`func(*list1)` → `*` 表示"把这个可迭代对象拆成多个位置参数，即解包操作符"
#### 示例代码
```
def demo(num, *args):
    print(type(args))

def show(*args):
    print(args)

if __name__ == "__main__":
    show(*"abc")
    show(*[1,2,3,4,5])
    show(*(1,2,3,4,5))
    show(*range(3))  # (0, 1, 2)
    show({"a":1,"b":2})  # ({'a': 1, 'b': 2},)
    show(*{"a":1,"b":2})  # ('a', 'b')
```

### kwargs
#### 打包与解包
- `**kw` 在函数参数中称为 **"关键字参数收集器"** 或 **"双星号参数"**，用于收集所有未明确命名的关键字参数。调用时只能接收**关键字参数**，不能接收位置参数
- **定义时**：`def func(**kwargs)` → `**` 表示"把传来的多个关键字参数打包成字典（kwargs）"
- **调用时**：`func(**dict)` → `**` 表示"把这个可迭代对象拆成多个关键字参数，即解包操作符"
#### 示例代码
```
def func(a, b, **kwargs):
    print(f"a={a}, b={b}")
    print(f"kwargs: {kwargs}")
    print(f"kwargs类型: {type(kwargs)}")

func(1, 2, c=3, d=4, e=5)
# 输出：
# a=1, b=2
# kwargs: {'c': 3, 'd': 4, 'e': 5}
# kwargs类型: <class 'dict'>
```
```
# 定义：打包操作
def process_data(**config):
    """处理数据，接收各种配置参数"""
    print("配置信息:")
    for key, value in config.items():
        print(f"  {key}: {value}")

    # 使用配置
    if config.get('debug', False):
        print("调试模式开启")

    return f"处理完成，使用算法: {config.get('algorithm', 'default')}"

# 准备配置字典
config_dict = {
    "algorithm": "random_forest",
    "max_depth": 10,
    "n_estimators": 100,
    "debug": True,
    "random_state": 42
}

# 调用：解包操作
result = process_data(**config_dict)
print(f"\n结果: {result}")
```

### 参数顺序
- `def xxx(普通参数, *args, 缺省参数)`
- 调用 `def(普通参数, x, x, x, x, x....(多值参数), a=123(关键字参数))`
- **Q**：`*args` 和 `**kwargs` 的作用？**A**：`*args` 接收任意数量的位置参数，打包成元组；`**kwargs` 接收任意数量的关键字参数，打包成字典。常用于装饰器、函数包装等场景。

## 匿名函数
### lambda 语法
- `lambda arg1, arg2: 一行代码`
- lambda 函数可以接受任意数量的参数，但只能返回一个表达式的值
- 匿名函数一般不直接调用，通常作为**函数的参数**使用
- `sum = lambda *args: sum(args)`
### 示例代码
```
people = [
    {"name": "张三", "age": 25},
    {"name": "李四", "age": 30},
    {"name": "王五", "age": 24},
]
people.sort(key=lambda x: x['age'])
print(people)

# 过滤出偶数
evens = list(filter(lambda x: x%2==0, [1,2,3,4]))
```

## 面试高频题

- **Q**：`==` 和 `is` 的区别？**A**：`==` 比较值，`is` 比较内存地址。
- **Q**：可变类型和不可变类型有哪些？**A**：不可变：int、float、str、tuple；可变：list、dict、set。
- **Q**：函数默认参数为什么不能用可变对象？**A**：因为默认参数在函数定义时创建一次，后续调用会共享同一个对象，导致意外修改。
- **Q**：`*args` 和 `**kwargs` 的作用？**A**：接收任意数量的位置参数和关键字参数。
- **Q**：装饰器的作用？写一个简单的装饰器。**A**：略。
- **Q**：生成器有什么优势？**A**：惰性求值，节省内存，适合处理大数据流。
- **Q**：列表推导式和生成器表达式的区别？**A**：列表推导式返回列表，立即计算所有元素；生成器表达式返回生成器，惰性计算。
- **Q**：`global` 和 `nonlocal` 的区别？**A**：`global` 用于在函数内修改全局变量，`nonlocal` 用于在嵌套函数内修改外层函数的变量。
- **Q**：如何交换两个变量的值？**A**：`a, b = b, a`（利用了元组解包）。
- **Q**：浅拷贝和深拷贝的区别？**A**：浅拷贝只复制第一层，深拷贝递归复制所有层。`copy.copy()` 和 `copy.deepcopy()`。

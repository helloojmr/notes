## 运算符与表达式
### 海象运算符 :=

#### 示例代码
```
# 传统写法：需要写两遍
line = input("请输入: ")
while line != "exit":
    print(f"你输入了: {line}")
    line = input("请输入: ")

# 使用海象运算符：一行搞定
while (line := input("请输入: ")) != "exit":
    print(f"你输入了: {line}")

# 语法错误写法！！！！！ line = input()是语句不是表达式
while (line = input()) != "exit":  # 语法错误！
    print(line)

# 读取文件时逐行处理直到结束
with open('log.txt') as f:
    while line := f.readline():
        process(line)  # 每读一行处理一行
```
### 表达式与语句
- **表达式**：**产生值**的东西 → "**这是什么？**" `line := input("请输入: ")`
- **语句**：**执行动作**的东西 → "**去做这个！**" `line = input()`
- **Q**：`:=` 和 `=` 有什么区别？**A**：`:=` 是赋值表达式，可以在表达式内部赋值，常用于简化代码；`=` 是赋值语句，不能出现在表达式上下文中。

## 引用与可变/不可变类型

### 引用概念
- 变量与数据是分开存储的，变量所占的内存空间存储的是数据所在内存的地址
- 变量中保存数据的地址，称为引用。Python 中所有数据的传递，传递的都是地址
- 赋值（=）即改变变量的引用
#### 示例代码
```
a = 1
b = a
print(id(a))  # 140706122627512  # id()查看变量的引用
print(id(b))  # 140706122627512
a = 2
print(id(a))  # 140706122627544
```
### 可变与不可变类型
- 可变与不可变类型：根据**内存地址中的数据**是否允许修改（不使用等号能否修改？改的是变量的引用还是实际地址中的数据呢？）
- 不可变类型：
  - 数字类型：int，float，bool
  - 字符串：str
  - 元组：tuple
- 可变类型：
  - 列表：list
  - 字典：dict
  - 集合：set

#### 示例代码
```
a = [1, 2]
b = [a, a]  # b的两个元素指向同一个列表
b[0].append(3)
print(b)  # [[1, 2, 3], [1, 2, 3]] 两个都变了！
```
#### 示例代码
```
def add_element(lst=[]):  # 默认参数为可变对象
    lst.append(1)
    return lst
print(add_element())  # [1]
print(add_element())  # [1, 1] ！因为默认参数在函数定义时只创建一次
```
### 默认参数陷阱与解决方案
- **解决方案**：默认参数用 `None`，内部判断
#### 示例代码
```
def add_element(lst=None):
    if lst is None:
        lst = []
    lst.append(1)
    return lst
```

## 作用域：局部变量与全局变量

### 基本概念
- **局部变量**（生命周期：函数执行期间）
  - 函数内部定义
  - 局部变量只能在当前函数内使用
  - 可以在不同函数内定义同名的局部变量
  - 形参可以理解为局部变量
  - return 即实现在函数被销毁前传递局部变量值出去
- **全局变量**（生命周期：模块加载到卸载；程序执行中）
  - 模块（.py）中，类/函数外
  - `global` 是一个**声明语句**，不是赋值语句。它告诉 Python "在这个函数里，`abc` 指的是全局变量，不是局部变量"
  - 函数内使用全局变量正确写法：先 `global x`，再 `x = value`
  - 函数内修改可变对象（列表/字典）的内容**不需要** `global`；重新赋值给变量**需要** `global`
  - `nonlocal` 用于嵌套函数中修改外层函数的变量
#### 示例代码
```
def func1():
    list1.append(10)
def func2():
    list1 = ["新列表"]
def func3():
    global list1
    list1 = ["新列表"]
if __name__ == "__main__":
    list1 = [1, 2]
    func1()
    print(list1)  # [1, 2, 10]
    func2()
    print(list1)  # [1, 2, 10]
    func3()
    print(list1)  # ['新列表']
```

## 输入与输出

### 输入输出
- `name=input("提示信息")`（获取键盘输入）
  - 代码执行至 input 时，等待输入结束；回车键结束输入
  - input 输入为字符串 `<class, 'str'>`
- `age=int(input("请输入年纪："))`（数据类型转换）
  - `int(str)`、`float(str)`、`str(int)`...
  - `tuple(s)`：将序列 s 转为元组
  - `list(s)`：将序列 s 转为列表
- **print**
  - `print('姓名：'+name+'\n\r年纪：'+str(age)+'\n\r性别：'+sex)`
  - 字符串.format()：`print('姓名：{}\n\r年纪：{}\n\r性别：{}\n\r'.format(name, age, sex))`
  - F-string：`print(f'姓名：{name}\n\r年纪：{age}\n\r性别：{sex}\n\r')`
  - `print()` 的 `end` 参数常用于自定义分隔符，如 `print(x, end='')` 不换行
  - `print(..., end='\n')`，end 参数默认就是 `'\n'`（换行），可改为 `''` 等自定义
  - 练习：提示输入两个数字后，格式化输出相加结果

#### 示例代码
```
num1 = int(input("请输入数字1:"))
num2 = int(input("请输入数字2:"))
print(f'{num1}+{num2}={num1 + num2}')
```
### 转义字符与运算符
- 转义字符：`\n` 换行，`\t` 制表符，`\r`
- 运算符
  - 算数运算符
    - `+ - * / //求商 %取余 **幂运算 2**3=8`
    - 优先级：()>幂运算>乘除求商取余>加减
    - `if (num1 % 2 == 0)`
  - 比较运算符 → bool
    - `== != > >= < <=`
  - 逻辑运算符 and or not

- **Q**：`==` 和 `is` 的区别？**A**：`==` 比较值是否相等，`is` 比较是否是同一个对象（内存地址）。例如 `a = [1,2]; b = [1,2]; a == b` 为 True，`a is b` 为 False。

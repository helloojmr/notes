## 流程控制概述

- **三大流程**：顺序、分支（判断）、循环
- **循环**：while、for in、break、continue、pass

## 条件判断：if-elif-else

### 基本语法
#### 示例代码
```
if 判断条件:
    pass
elif 判断条件:
    pass
else:
    pass
```
### 注意事项
- if 与比较运算符/逻辑运算符结合；if 判断的嵌套

## 循环
### while 循环

#### 基本语法示例
```
while 判断条件：
    pass
```
#### 指定条件循环示例
```
# 指定条件的循环
while i < 100:
    xxxx
    i += 1
```
#### 无限循环

#### 说明
- 死循环、无限循环
#### 无限循环示例
```
# 可控的无限循环，常用于重试机制
while True:
    xxxx
    if xxx:
        break
    xxxx
    xxxx
    continue
```
#### break 与 continue

#### 说明
- 使用 `if break` 跳出循环
- 使用 `continue` 结束本次循环

### for in（遍历）

#### 示例代码
```
for x in xxx:
    pass

for x in range(n):
    # range(n) 范围是 [0,n)
    # range(start,end) 范围是 [start,end)
    pass
```
#### in 与 not in
- `in / not in`
  - **数据 in 容器** True or False
  - 对于 dict 来说，判断的是有没有这个 key

## 循环的 else 分支
### for-else
#### 示例代码
```
for item in sequence:
    # 循环体
    if condition:
        break  # 提前退出循环
else:
    # 如果循环正常结束（没有遇到break），执行这里
    # 场景：找东西，找到了就break，没找到（正常循环完）就执行else
    # 场景：遍历所有重试后失败
```

### while-else

#### 示例代码
```
import requests
import time

max_retries = 3
attempt = 0

while attempt < max_retries:
    print(f"第{attempt+1}次尝试...")
    try:
        response = requests.get("https://api.example.com")
        if response.status_code == 200:
            print("请求成功！")
            break  # 成功，退出循环
    except Exception as e:
        print(f"请求失败: {e}")

    attempt += 1
    time.sleep(1)  # 等待1秒再重试
else:
    # 如果尝试了max_retries次都没成功（没有break）
    print(f"尝试{max_retries}次后仍然失败")
    print("执行备用方案...")
    # 比如：使用缓存数据、返回默认值等
```
#### 应用示例
- while-else 常用于重试机制，全部失败后执行备用方案

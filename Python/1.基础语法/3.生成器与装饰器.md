## 可迭代对象与迭代器
### 基本概念

#### 说明
- **可迭代类型**：str、list、tuple、dict、set
- **可迭代对象**：实现了 `__iter__()` 方法或 `__getitem__()` 方法的对象，它能够一次返回一个元素，供 `for` 循环、`list()` 等使用
- **能用 `for item in X:` 循环的就是可迭代对象！**
- **迭代器**：实际执行遍历操作的"工具"
  - 它从可迭代对象中**一次只取一个**元素
  - 它会**记住取到哪了**（状态）
  - 取完了就**停止工作**（抛出 StopIteration）
  - 不能**倒回去重取**（一次性）
- **所有迭代器都是可迭代的，但并非所有可迭代对象都是迭代器。**
#### 示例代码
```
# 1. 创建歌单（可迭代对象）
playlist = ["七里香", "晴天", "夜曲", "发如雪"]  # 这只是歌单
# 2. 拿到点歌机（迭代器）
player = iter(playlist)  # iter() 就像"把歌单放入点歌机"
# 3. 开始点歌（迭代）
print(next(player))  # 第一次按"下一首" → "七里香"
print(next(player))  # 第二次按"下一首" → "晴天"
print(next(player))  # 第三次按"下一首" → "夜曲"
print(next(player))  # 第四次按"下一首" → "发如雪"
# print(next(player))  # 再按就报错：StopIteration（没歌了！）
```

## 生成器
### for 循环的真相
#### 示例代码

```
fruits = ["苹果", "香蕉", "橘子"]
for fruit in fruits:
    print(fruit)

# 等价于：
fruits = ["苹果", "香蕉", "橘子"]
iterator = iter(fruits)
while True:
    try:
        fruit = next(iterator)
        print(fruit)
    except StopIteration:
        break
```

### yield 生成器
#### 示例代码

```
def data_stream():
    """模拟源源不断的数据"""
    data = ["包1", "包2", "包3", "包4", "包5"]
    for item in data:
        yield item  # 👈 关键在这里！
        # 函数在这里暂停，等待下次next()
        # 下次next()时，从for循环的下一次迭代继续

# 创建生成器（迭代器）
stream = data_stream()  # 注意：函数不会立即执行！

# 模拟网络请求：一次请求一个数据包
print("客户端: 请求数据")
packet = next(stream)  # 1. 执行到第一个yield，返回"包1"，暂停
print(f"服务器: 发送 {packet}")

print("\n客户端: 再请求数据")
packet = next(stream)  # 2. 从暂停处继续，执行下一个循环，返回"包2"，暂停
print(f"服务器: 发送 {packet}")

print("\n客户端: 再请求数据")
packet = next(stream)  # 3. 继续，返回"包3"，暂停
print(f"服务器: 发送 {packet}")

# ... 可以一直请求，直到数据发完
```

### 生成器的真相
#### 底层原理
```
# 你以为你写的是函数，其实Python在背后做了很多事！
def my_generator():
    yield 1
    yield 2
    yield 3

# Python 悄悄做的事情（概念上）：
class HiddenIterator:
    def __init__(self):
        self.state = 0  # 记录执行到哪里了

    def __iter__(self):
        return self

    def __next__(self):
        if self.state == 0:
            self.state = 1
            return 1
        elif self.state == 1:
            self.state = 2
            return 2
        elif self.state == 2:
            self.state = 3
            return 3
        else:
            raise StopIteration

# 当你调用 my_generator() 时
gen = my_generator()  # 实际上返回的是 HiddenIterator 的实例！
```
#### 常见问答
- **Q**：迭代器和生成器的区别？**A**：迭代器是实现了 `__iter__` 和 `__next__` 的对象，生成器是使用 `yield` 的简化迭代器。生成器属于迭代器的一种。

## 装饰器
### 基本概念

#### 说明
- **作用**：在不修改原函数代码的前提下，为其添加额外功能（如日志、计时、重试、权限校验）。
- **语法**：使用 `@装饰器名` 放置在函数定义上

### 基础装饰器
#### 示例代码
```
def decorator(func):
    def wrapper(*args, **kwargs):
        # 执行前操作
        result = func(*args, **kwargs)  # 调用原函数
        # 执行后操作
        return result
    return wrapper
```
#### 要点说明

#### 说明
- `*args, **kwargs` 保证能接收任意参数。
- 内部必须返回原函数的返回值。

### 带参数的装饰器（三层嵌套）
#### 示例代码
```
def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(n):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)  # 传参
def hello():
    print("Hi")
```
#### 执行流程

#### 说明
- `@repeat(3)` 首先调用 `repeat(3)`，返回内部的 `decorator`。
- 然后 `decorator` 接收原函数 `greet`，返回 `wrapper`。
- 最终 `greet` 被替换为 `wrapper`，并且 `n=3` 被保留在**闭包**中。

### 闭包
#### 概念说明

#### 说明
- **闭包**是指在一个内部函数中，引用了外部函数的变量，并且外部函数返回了内部函数。这样，即使外部函数已经执行结束，内部函数仍然可以访问那些外部函数的变量。
- 简单来说：**闭包 = 函数 + 它引用的外部变量**。
- 闭包的构成条件：
  1. 有**嵌套函数**（函数内部定义另一个函数）。
  2. 内部函数**引用了外部函数的变量**（包括参数）。
  3. 外部函数**返回内部函数**。
#### 示例代码
```
# 闭包
def create_api_client(base_url):
    def request(path):
        return f"请求 {base_url}{path}"
    return request

client = create_api_client("https://api.example.com")
print(client("/users"))  # 请求 https://api.example.com/users
```

### 多个装饰器执行顺序
#### 规则说明

#### 说明
- **装饰顺序**：从下往上（靠近函数的先装饰）
- **执行顺序**：从上往下（先进入外层装饰器的前置代码）
#### 示例代码
```
def decorator_a(func):
    def wrapper():
        print("A before")
        func()
        print("A after")
    return wrapper

def decorator_b(func):
    def wrapper():
        print("B before")
        func()
        print("B after")
    return wrapper

@decorator_a
@decorator_b
def test():
    print("test")

test()

# 输出：
# A before
# B before
# test
# B after
# A after
```
#### 要点说明
- 相当于 `test = decorator_a(decorator_b(test))`。
- 先执行 `decorator_b` 对 `test` 进行包装，得到新函数，再被 `decorator_a` 包装。
- 调用时，先进入 `decorator_a` 的 `wrapper`，打印 "A before"，然后调用被 `decorator_b` 包装后的函数，打印 "B before"，再调用原函数，然后依次退出。

### 内置装饰器（用于类中）

#### 说明
- `@staticmethod`：静态方法，无需实例调用。
- `@classmethod`：类方法，第一个参数为 `cls`。
- `@property`：将方法变成属性调用，可定义 getter/setter

### 装饰器实战案例
#### 计时器：接口耗时统计
```
# 计时器：在接口自动化测试中，统计每个接口的响应时间，用于性能分析。
import time

def timer(func):
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        cost = time.time() - start
        print(f"{func.__name__} 耗时 {cost:.4f} 秒")
        return result
    return wrapper

@timer
def test_login():
    time.sleep(1)  # 模拟网络请求
    return "ok"

test_login()
```
#### 重试机制：处理不稳定测试
```
# 重试机制（处理不稳定测试）
def retry(max_attempts=3, delay=1):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for attempt in range(1, max_attempts+1):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    print(f"第{attempt}次尝试失败：{e}")
                    if attempt == max_attempts:
                        raise
                    time.sleep(delay)
        return wrapper
    return decorator

@retry(max_attempts=3, delay=2)
def unstable_request():
    import random
    if random.random() < 0.7:
        raise ConnectionError("网络错误")
    return "成功"

print(unstable_request())
```

## 正则表达式基础

### 概念

- **定义**：用一套特殊符号描述字符串匹配规则，从文本中查找/提取/替换符合规则的内容。
- **本质**：一种"模式(pattern)"，匹配的是规则而非具体字符。
- **对应语言**：Python 用内置 `re` 模块；几乎所有语言都有正则实现(JS、Java、Go)。
- **实战要点**：日志分析、接口参数提取、断言校验、数据清洗四大场景都靠它，是核心技能。

### 应用场景

- 从响应/日志中提取动态值(token、订单号、ID)。
- 断言校验：响应文本是否符合格式(如邮箱、手机号、UUID)。
- 日志分析：按模式过滤错误码、异常堆栈。
- 数据清洗：批量替换/删除文本中的噪声。

## 元字符与匹配模式

### 元字符速查
#### 字符匹配

- `.`：匹配任意单个字符(换行除外)。
- `\d`：数字 `[0-9]`；`\D`：非数字。
- `\w`：字母数字下划线 `[A-Za-z0-9_]`；`\W`：取反。
- `\s`：空白字符(空格/tab/换行)；`\S`：非空白。
- `\`：转义，匹配特殊字符本身，如 `\.` 匹配小数点。

#### 数量限定

- `*`：前一个字符出现 0 次或多次。
- `+`：出现 1 次或多次。
- `?`：出现 0 次或 1 次。
- `{n}`：恰好 n 次；`{n,}`：至少 n 次；`{n,m}`：n 到 m 次。

#### 位置锚点

- `^`：字符串开头。
- `$`：字符串结尾。
- `\b`：单词边界(了解)。

#### 字符类

- `[abc]`：匹配 a/b/c 任意一个。
- `[a-z]`：匹配 a-z 区间。
- `[^abc]`：匹配非 a/b/c 的字符。

#### 分组与或

- `(pattern)`：捕获分组，可提取也可整体应用数量限定。
- `|`：或，如 `cat|dog` 匹配 cat 或 dog。
- `(?:pattern)`：非捕获分组，只分组不提取(了解)。

### 贪婪与非贪婪

#### 贪婪匹配

- 默认行为：`.*` 尽可能多地匹配，一直到**最后一次**符合条件的位置。
- 陷阱：提取多个 token 时容易"一口吞"。

#### 示例

```
text = 'token1="abc" token2="def"'
re.findall(r'"(.*)"', text)
# 结果: ['abc" token2="def']  ← 贪婪，吞到最后一个引号
```

#### 非贪婪匹配

- `.*?` 尽可能少地匹配，取**第一次**符合条件的位置。
- 提取场景 90% 用非贪婪。

#### 示例

```
re.findall(r'"(.*?)"', text)
# 结果: ['abc', 'def']  ← 非贪婪，逐个提取
```

#### 面试话术

- `.*` 贪婪吞到最后一个，`.*?` 非贪婪取第一个；提取多个值时用 `.*?`。

## Python re 模块

### 常用方法

#### search 与 match

- `re.search(pattern, text)`：全文中找第一处匹配，返回 Match 对象或 None。
- `re.match(pattern, text)`：只从**开头**匹配，开头不匹配即 None。
- 区别：search 找全文，match 死磕开头。

#### findall 与 finditer

- `re.findall(pattern, text)`：返回所有匹配的**列表**(常用)。
- 有分组时返回分组元组列表：`re.findall(r'(\w+)=(\d+)', s)` → `[('a','1'),('b','2')]`。
- `re.finditer(pattern, text)`：返回迭代器，数据量大时省内存。

#### sub 与 split

- `re.sub(pattern, repl, text)`：替换所有匹配，如脱敏手机号。
- `re.split(pattern, text)`：按正则分割字符串。

#### compile

- `re.compile(pattern)`：预编译，多次使用同一正则时提升性能。
- 典型用法：在循环/高频调用前编译一次。

### flags 标志

- `re.IGNORECASE`(re.I)：忽略大小写。
- `re.MULTILINE`(re.M)：`^`/`$` 对每行生效。
- `re.DOTALL`(re.S)：`.` 匹配换行，多行文本提取用。
- 用法：`re.findall(pattern, text, re.I)` 或编译时传入。

## 分组与反向引用

### 捕获组

- 括号即分组，按左括号顺序编号从 1 开始。
- `group(0)` 整个匹配，`group(1)` 第一个分组。

#### 示例

```
m = re.search(r'(\d{4})-(\d{2})-(\d{2})', '日期 2026-08-09 结束')
m.group(1)  # '2026'
m.group(2)  # '08'
```

### 命名分组

- `(?P<name>pattern)` 给分组起名，`group('name')` 取值。
- 可读性好，提取字段多时推荐。

#### 示例

```
m = re.search(r'(?P<year>\d{4})-(?P<month>\d{2})', '2026-08')
m.group('year')   # '2026'
m.group('month')  # '08'
```

## 实战案例

### 日志提取错误码

- 场景：从日志中提取所有错误码 `ERROR-404`、`ERROR-500`。

#### 示例

```
logs = 'timeout ERROR-500\nrefused ERROR-404'
codes = re.findall(r'ERROR-(\d{3})', logs)
# 结果: ['500', '404']
```

### 提取 token 与订单号

- 场景：从接口响应/HTML 中提取动态值，供后续请求使用。

#### 示例

```
text = '{"token":"abc.def.ghi","orderNo":"ORD20260809001"}'
token = re.search(r'"token":"(.*?)"', text).group(1)
order = re.search(r'"orderNo":"(.*?)"', text).group(1)
```

### 断言中的正则

- 场景：校验响应中邮箱、手机号、UUID 格式。

#### 示例

```
import re
resp = 'email: test@qq.com'
assert re.search(r'[\w.-]+@[\w.-]+\.\w+', resp), '邮箱格式不对'
```

## 面试高频题

- **Q**：`.*` 和 `.*?` 有什么区别？**A**：`.*` 贪婪，匹配到最后一个符合条件的位置；`.*?` 非贪婪，匹配第一个；提取多个值时用非贪婪，否则会"一口吞"。
- **Q**：`re.search` 和 `re.match` 区别？**A**：search 在全文找第一处匹配；match 只从字符串开头匹配，开头不匹配返回 None。
- **Q**：如何提取响应里的 token？**A**：`re.search(r'"token":"(.*?)"', text).group(1)`，非贪婪 + 捕获组；响应是 JSON 也可直接 `resp.json()["data"]["token"]`。
- **Q**：`re.findall` 带分组返回什么？**A**：返回分组元组列表，如 `[('a','1'),('b','2')]`；不带分组返回匹配字符串列表。
- **Q**：大量文本匹配时怎么提升性能？**A**：`re.compile` 预编译一次复用；数据量极大用 `finditer` 迭代而非 findall 一次性加载。
- **Q**：多行文本里 `.` 匹配不到换行怎么办？**A**：加 `re.DOTALL`(re.S) 标志，让 `.` 匹配包括换行的任意字符。

## 字符串（str）
### 定义方式
- 引号："xxxx" / 'xxxx' / """xxxx"""
### 示例代码
```
str1 = "xxxx"
str2 = 'xxxx'
str3 = """xxxx"""
str4 = "i'm xxx"
str5 = 'i\'m xxx'   # 单引号内包含单引号，需用反斜杠转义
str6 = r''  # 原生字符串，字符串中的\不转义
```

### find
#### 语法说明
- str.**find**(x, start, end)：返回子串第一次出现的起始索引，没有返回 -1；start 开启检索位置，end 为终止检索位置
#### 示例代码
```
# 提取域名
url = "https://www.baidu.com/search"
start = url.find('www.') + 4
end = url.find('/', start)
domain = url[start:end] if end != -1 else url[start:]
print(domain)
```

### replace
#### 语法说明
- str.**replace**(old, new, count)：字符串是不可变的，所以 `replace()` **返回一个新字符串**，原字符串不变；大小写敏感
#### 示例代码
```
str1 = "good good study"
# 将第一个good替换为Good
str2 = str1.replace("good", "Good", 1)
# 将第二个good替换为Good
str3 = str1.replace("good", "Good").replace("Good", "good", 1)
print(str3)
```

### split 与 join
#### 语法说明
- str.**split**(sep, 最大分割次数)：将字符串按指定字符串 sep 分隔，返回分割后的 list
- str.**join**(字符串列表/元组)：split 的逆操作
#### 示例代码
```
text = "Hello   World\tPython\nProgramming"
parts = text.split()
print(parts)  # ['Hello', 'World', 'Python', 'Programming']

text1 = ",".join(parts)
print(text1)  # Hello,World,Python,Programming
```
#### 常见问答
- **Q**：如何反转字符串？**A**：`s[::-1]`

## 列表（list）
### 常用操作
- 定义方式：
  - 方式 1，类实例化：定义空列表 `list1=list()`；定义非空列表 `list1=list(可迭代对象)`
  - 方式 2，使用 `[a,b,c,d]` 定义
- **index(数据)**：找到返回下标，没有直接报错。列表只有 index()；str 有 index() 和 find()
- **list.count(数据)**：统计指定数据在列表中出现的次数
- **list.append(数据)**：返回 None
- **list.pop(index)**：根据 index 删除数据，默认删除最后一个，返回删除的数据
- **修改数据**：`list[index] = newdata`
- **list.reverse()**：直接反转当前列表；`[::-1]` 得到一个新列表，原列表不动
- **list.sort()**：排序，要求 list 中数据类型一致，直接操作原列表；默认升序，`reverse=True` 降序
- 列表推导式：`users = [f"user{i}" for i in range(10)]`
- enumerate：同时获取索引和值
### 示例代码
```
for idx, value in enumerate(['a','b']):
    print(idx, value)
```
#### 二维 list
- **二维 list**：`list[list,list]`，访问 `list[0][1]`

## 元组（tuple）
### 基本概念
- 不能修改，只能查询（index、count、下标、切片）
- 定义方式：
  - `tuple1=tuple()` 空元组
  - `tuple2=tuple([1,2,3])` 将列表（其他可迭代类型）转换为元组
  - `tuple3=(1,2,3)`
  - `tuple4=(1,)`、`tuple5=(1)`（注意：单个元素要加逗号）
- 组包（pack）：`tuplex=1,2,3,4`
- 解包（unpack）：
### 示例代码
```
tuplex = 1, 2, 3, 4
print(tuplex)
a, b, c, d = tuplex
a, b, c, d = [1, 2, 3, 4]
a, b, c, d = 'abcd'
print(a, b, c, d)

a, b = 10, 20
c = (b, a)   # 组包 pack：c = (20, 10)
a, b = c     # 解包 unpack：a=20, b=10
print(a, b)  # 20,10
```
### 多返回值
- return 返回多个数据值，通过**元组**：
### 示例代码
```
def calc(a, b):
    return a+b, a-b  # 元组括号可以省略

if __name__ == "__main__":
    result = calc(10, 20)  # 这里也可以拆包接收
    print(result)  # (30, -10)
```

## 字典（dict）
### 常用操作
- 定义方式：类实例化 `dict1=dict()`；空字典 `{}`；`{x:x,}`
- 字典无下标
- **查询**：`dict[key]` 不存在报错；`dict.get(key)` 不存在返回 None
- **添加/修改**：`dict[key]=value`（key 不存在则添加，存在则修改）
- **删除**：`dict.pop(key)`（返回删除的 value）
- 字典推导式：`{k: v for k, v in zip(keys, values)}`
- `setdefault` 和 `defaultdict` 用于处理缺失键
### 遍历
#### 遍历 key
  - 遍历 key
#### 示例代码
```
for key in dict:
    print(key)

for key in dict.keys():
    print(key)
```
#### 遍历 value
  - 遍历 value
#### 示例代码
```
for key in dict:
    print(dict[key])

for value in dict.values():
    print(value)
```
#### 遍历键值对
  - 遍历键值对
#### 示例代码
```
for key, value in dict.items():
    print(key, value)
```

## 集合（set）

- 集合中的数据不重复
- 去重是集合的典型应用：`set(list)`，如 `unique_ids = set([1,2,2,3])  # {1,2,3}`

## 数据结构操作（有序序列）

1. **下标（索引）**
  - `x[下标]`
  - 从 0 开始，Python 支持负数下标，`[-1]` 表示最后一个位置的数据
2. **切片**
  - 获取下标为**等差数列**的多个数据
  - `x[start:end:step]`
  - start 开始下标，end 结束下标（取不到），step 步长（相邻两个坐标的差值）
  - 正步长，省略始→从头起，省略末→到尾止
  - 负步长，正相反，省略始→从尾起，省略末→到头止
  - **省略的含义不是"0"或"长度"，而是"序列的起点"或"终点"**
  - **深拷贝：`[:]`；反转序列：`[::-1]`**
  - `[start], [start+step], [start+step*2]...[end(取不到)]`

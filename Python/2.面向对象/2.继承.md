## 继承的概念
### 继承概述


#### 说明
- 实现代码的重用，相同的代码不需要反复编写。
- 使用继承时需要考虑类与类之间是否是 **is...a** 的关系，不能盲目使用继承
- 定义的类默认继承 Object 类。继承既有传递性，对象调用方法时由子类向父类找...
### 基本语法
```
class 类名(父类名):
    pass
```

### 继承在测试框架中的应用
#### 基类与子类

##### 说明
- **基类封装通用方法**：如 `BasePage` 封装打开页面、等待元素等通用操作。
- **子类实现具体页面**：如 `LoginPage` 继承 `BasePage`，实现登录相关的具体方法。
##### 示例代码
```
class BasePage:
    def __init__(self, driver):
        self.driver = driver

    def open(self, url):
        self.driver.get(url)

    def find_element(self, locator):
        return self.driver.find_element(*locator)

class LoginPage(BasePage):
    def input_username(self, username):
        self.find_element(("id", "username")).send_keys(username)

    def input_password(self, password):
        self.find_element(("id", "password")).send_keys(password)

    def click_login(self):
        self.find_element(("id", "login-btn")).click()
```

### 重写
- 覆盖式重写/扩展式重写：子类可以重写父类方法，也可以扩展（通过 `super()` 调用父类方法后再添加逻辑）。

### super()

#### 说明
- **`super()`** 创建一个 `super` 对象（代理对象）
- **`super()` 的参数隐含了什么？**
  - Python 自动传入：`super(Cat, self)` 或 `super(type(self), self)`
  - 即：第一个参数是当前类 `Cat`，第二个参数是当前实例 `self`
- 当执行 `super().__str__()` 时：
  - super() 返回一个代理对象，指向 Animal
  - 这个代理对象知道 self 是 Cat 的实例
  - 调用 `__str__()` 时，会自动把 self 传递给 `Animal.__str__`
- **自动传递 `self`**：
  - 当你调用 `代理对象.__str__()` 时，代理并不会自己执行，也不会让 `Animal` 类去执行
  - 代理会说："`Animal` 类，请指导我手里的这位 **`self`**（猫实例）如何执行你的 `__str__` 方法"
  - 这就是所谓的**方法解析顺序**，它确保了即使逻辑来自父类，操作的数据（`self`）依然是子类的实例
  - 在多重继承中，`super()` 的查找顺序遵循 **MRO（方法解析顺序）**，可通过 `类名.__mro__` 查看
- **Q**：`super().__init__()` 和 `父类名.__init__(self)` 有什么区别？**A**：`super()` 支持多重继承，会按照 MRO 顺序调用父类，避免重复调用；直接写父类名会硬编码，在多重继承中可能导致问题。推荐使用 `super()`。

### 钻石继承（多重继承 MRO）
#### 示例代码
```
class A:
    def __init__(self):
        print("A 初始化")

class B(A):
    def __init__(self):
        print("B 开始")
        super().__init__()
        print("B 结束")

class C(A):
    def __init__(self):
        print("C 开始")
        super().__init__()
        print("C 结束")

class D(B, C):
    def __init__(self):
        print("D 开始")
        super().__init__()
        print("D 结束")

d = D()
```
#### 执行顺序解析
- 关键在于理解 `super()` 在这个"继承队伍"里的传递顺序：
  1. **起点是 D**：你创建了 `D()`，所以先打印 "D 开始"，然后遇到 `super().__init__()`。
  2. **传给 B**：Python 看了看继承顺序 `D(B, C)`，决定把话筒递给第一个父类 `B`。`B` 开始执行，打印 "B 开始"。
  3. **B 不独占**：`B` 很懂事，它执行完自己的逻辑后，也喊了一声 `super().__init__()`。它没有直接去找 `A`，而是说："下一位请接话"。
  4. **传给 C**：根据 MRO 队伍顺序，`B` 的下一位是 `C`（而不是 `A`，这是最容易想不通的地方）。所以 `C` 开始执行，打印 "C 开始"。
  5. **C 也协作**：`C` 执行完自己的逻辑后，也喊了一声 `super().__init__()`，把话筒传给了它的"下一位"。
  6. **终于到 A**：这时候，队伍里 `C` 的下一位才是 `A`。`A` 打印 "A 初始化"。`A` 里面没有 `super()` 了，所以它执行完就结束了。
  7. **回溯**：`A` 结束后，流程回到 `C`，`C` 打印 "C 结束"；`C` 结束后，流程回到 `B`，`B` 打印 "B 结束"；最后回到 `D`，打印 "D 结束"。

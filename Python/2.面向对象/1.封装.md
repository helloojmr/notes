## 测试中的应用

- **测试框架设计**：用类封装业务模块（如用户、订单），提高脚本可读性和复用性
- **Page Object 模式**：Web 自动化中，每个页面封装成一个类，方法对应页面操作
- **测试数据模型**：用类定义数据实体（如 User、Product），方便数据构造和校验
- **工具开发**：编写测试工具时，用类组织功能，提供清晰的接口
- **断言封装**：将常用断言封装成类方法，统一管理

## 封装的概念

### 封装与 self

#### 核心概念


##### 说明
- 根据需求将属性和方法封装到一个**抽象的类**中；类（类名、属性、方法）→ 对象
- **self 的本质**：`self` 是实例对象本身，在调用实例方法时由 Python 自动传递。
- 在类内部，必须用 `self.` 访问实例属性和方法；在类外部，通过实例对象调用方法时，不需要也不能传递 `self`。

##### 示例代码

```
class XXX:
    def __init__(self):
        # 在构造方法中初始化实例变量
        self.vvv = 10

    def www(self, abc):
        # 现在可以访问self.vvv了
        return self.vvv + abc  # 10 + 10 = 20

xxx = XXX()
result = xxx.www(10)
print(f"结果: {result}")  # 结果: 20
```

### 常见错误


#### 说明
- **常见错误**：类内直接用 self 定义变量（此时 self 还不存在）

#### 错误示例

```
class XXX:
    self.vvv = 10  # ❌ 这里self是什么？还没创建实例呢！
    # Python执行到这里时：
    # 1. 类XXX还没创建完
    # 2. 没有任何XXX的实例存在
    # 3. 所以self这个变量根本不存在！
```

### 类变量与实例变量


#### 说明
- **类变量 vs 实例变量**：
  - 类变量：类内直接定义，生命周期为类存在期间，所有实例共享
  - 实例变量：必须在 `__init__` 或其他方法内用 `self.` 定义，生命周期为实例存在期间

#### 示例代码

```
class XXX:
    # ✅ 类变量可以在这里定义
    class_var = "我是类变量"

    def __init__(self):
        # ✅ 实例变量必须在这里（或其他方法内）定义
        self.instance_var = "我是实例变量"

    def method(self):
        # ✅ 这里可以访问self
        print(self.instance_var)
```

### 三类方法

#### 示例代码（Student 示例）

```
class Student:
    # 类变量：所有学生共享
    school = "清华大学"
    student_count = 0

    def __init__(self, name, age):
        # 实例变量：每个学生独有
        self.name = name
        self.age = age

        # 修改类变量
        Student.student_count += 1

    # 实例方法，学生个人学习
    def study(self, hours):
        # 局部变量：只在方法内有效
        energy = hours * 10

        # 访问实例变量
        print(f"{self.name} 学习了{hours}小时")

        # 访问类变量
        print(f"学校: {Student.school}")

        return f"消耗了{energy}能量"

    # 类方法：处理班级事务
    @classmethod
    def get_school_info(cls):  # cls就是类本身，相当于在类方法中写Student
        # 类方法：只能访问类变量
        return f"{cls.school} 有 {cls.student_count} 名学生"

    @classmethod
    def change_school(cls, new_school):
        """修改学校（影响所有学生）"""
        cls.school = new_school
        return f"学校已更名为: {cls.school}"

    @classmethod
    def create_from_birth_year(cls, name, birth_year):
        """通过出生年份创建学生"""
        from datetime import datetime
        current_year = datetime.now().year
        age = current_year - birth_year
        return cls(name, age)

    # 静态方法，与学生相关的工具
    @staticmethod
    def is_valid_name(name):
        """验证学生姓名是否有效"""
        if not name or not isinstance(name, str):
            return False
        # 姓名长度2-10个字符，只包含中文或字母
        if len(name) < 2 or len(name) > 10:
            return False
        # 检查是否只包含中文、字母和空格
        import re
        return bool(re.match(r'^[\u4e00-\u9fa5a-zA-Z\s]+$', name))

# 使用
stu1 = Student("张三", 20)
stu2 = Student("李四", 21)

print(stu1.study(3))  # 张三 学习了3小时\n学校: 清华大学\n消耗了30能量
print(Student.get_school_info())  # 清华大学 有 2 名学生

test_names = ["张三", "Alice Smith", "123", "", "VeryLongNameIndeed"]
for name in test_names:
    valid = Student.is_valid_name(name)
    print(f"'{name}' 是否有效: {valid}")
```

#### 三类方法总结

- 现在 `Student` 类就有了完整的三类方法：
  - **实例方法**：处理学生个人数据
  - **类方法**：处理班级级别事务
  - **静态方法**：提供学生相关的工具函数

## 魔法方法

### 常用魔法方法


#### 说明
- Python 中 `__xx__` 方法，魔法方法，满足条件下自动调用
- **`__init__` 初始化方法**
  - 调用时机：创建对象时，自动调用
  - 应用场景：初始化对象，给对象添加属性，创建对象时传递实参
- **`__str__` 方法**
  - 调用时机：print(obj) 时，自动调用
  - 如果 class 内未定义 `__str__` 方法，print(obj) 打印的是对象的引用地址
  - 定义后打印 `__str__` 的返回值，它必须返回字符串
  - 应用场景：使用 print(obj) 打印对象的属性信息
- **`__repr__`**：在交互式环境中展示对象，常用于调试。交互式解释器中直接输入变量名会调用
- **`__eq__`**：定义对象相等比较，用于断言两个对象是否相等

#### 示例代码

```
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"User(name='{self.name}', age={self.age})"

    def __eq__(self, other):
        if not isinstance(other, User):
            return False
        return self.name == other.name and self.age == other.age

user1 = User("张三", 20)
user2 = User("张三", 20)
print(user1)          # User(name='张三', age=20)
print(user1 == user2) # True
```

### 应用场景


#### 说明
- 应用：在测试断言中，可以直接比较两个对象是否相等，而不用逐个字段断言
- **`dir(obj)`**：查看对象的所有属性及方法

#### 示例代码

```
class Cat:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"{self.age}岁的{self.name}"

cat = Cat("小猫", 2)
print(cat)
print(dir(cat))
```

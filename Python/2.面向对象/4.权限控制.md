## 访问权限
### 三种访问权限
- **公有**
  - 命名方式：`name`
  - 外部访问：✅ 可以
  - 子类访问：✅ 可以
  - 用途：对外接口
- **受保护**
  - 命名方式：`_name`
  - 外部访问：⚠️ 可以（但不推荐）
  - 子类访问：✅ 可以
  - 用途：内部实现，子类可扩展
- **私有**
  - 命名方式：`__name`
  - 外部访问：❌ 不能直接访问
  - 子类访问：❌ 不能直接访问
  - 用途：严格内部实现，防止外部修改
### 对象与成员

#### 说明
- **对象，python中一切皆对象**
  - 类对象：代码执行时，解释器会自动创建类
    - 使用类对象创建实例对象
    - 存储类的特征值（类属性）
  - 实例对象：实例化类即为实例对象。
    - 存储实例的特征值（实例属性）
- 变量
  - 实例变量
    - 每个实例对象具有的特征值，通常在init方法中self.定义
    - 每个实例对象保存自己的实例属性，即内存中存在多份；每个实例独立，适合存储对象特有数据。
    - 访问：实例对象.实例变量
  - 类变量
    - 整个类的特征值，通常在类中（非方法内）定义
    - 只有类对象保存一份，即内存中只有一个；所有实例共享，适合存储配置、常量、计数器等。
    - 访问：类对象.类变量
- 方法
  - 实例方法
    - 如果方法中需要使用实例属性，则这个方法**必须**定义为实例方法
    - 参数(self，...)
    - 调用：对象名.方法（）
  - 类方法
    - 如果一个方法不需要使用实例属性，只需要使用类属性，则**可以**定义为类方法（建议）
    - @classmethond def func(cls):
    - 参数(cls)，即类对象
    - 调用：
      - 类名.方法名（）
      - 实例对象.方法名（）
  - 静态方法
    - 如果一个方法使用实例属性，也不需要使用类属性，则**可以**定义为静态方法
    - @staticmethod def 方法名()
    - 参数无要求
    - 调用：
      - 类名.方法名（）
      - 实例对象.方法名（）


- **Q**：`self` 的作用是什么？为什么实例方法都要带 self？**A**：`self` 代表实例本身，在实例方法中必须作为第一个参数，不能省略。调用时Python自动传递。
- **Q**：类变量和实例变量的区别？**A**：类变量所有实例共享，实例变量每个实例独立。类变量适合存储全局配置，实例变量存储对象特有数据。
- **Q**：`@classmethod` 和 `@staticmethod` 的区别？**A**：类方法第一个参数是 `cls`，可以访问类属性；静态方法没有特殊参数，不能访问类属性，相当于独立函数。类方法常用于工厂方法，静态方法用于工具函数。
- **Q**：什么是 MRO？如何查看？**A**：MRO（Method Resolution Order）是方法解析顺序，决定多重继承时调用哪个父类的方法。可用 `类名.__mro__` 查看。
- **Q**：Python 如何实现私有属性？**A**：通过双下划线前缀 `__` 实现名称改写，外部不能直接访问，但可通过 `_类名__属性` 强制访问（不推荐）。
- **Q**：`@property` 的作用？**A**：将方法变成属性调用，可以添加 getter/setter 逻辑，实现受控访问。
- **Q**：什么是多态？Python 中如何体现？**A**：多态指不同对象对同一消息做出不同响应。Python 通过鸭子类型实现，只要对象有相应方法即可调用，不强制继承。
- **Q**：什么是鸭子类型？**A**：“如果它走起来像鸭子，叫起来像鸭子，那么它就是鸭子。”在编程中，不关心对象的具体类型，只关心它是否有某个方法。
- **Q**：如何设计一个线程安全的单例类？**A**：（高级题）可以使用元类或装饰器实现，但一般用模块级变量即可，因为模块在Python中是天然单例。
- **Q**：在自动化测试中，你如何应用 Page Object 模式？**A**：每个页面封装成一个类，包含页面元素定位和操作方法。测试用例只调用这些方法，不直接操作元素，提高可维护性。
### 示例代码
```
class Person:  
    """权限演示类"""  
  
    # 类属性权限  
    public_class_attr = "公有类属性"  
    _protected_class_attr = "受保护类属性"  
    __private_class_attr = "私有类属性"  
  
    def __init__(self, name, age, salary):  
        # 公有实例属性 - 外部可以直接访问和修改  
        self.name = name  
  
        # 受保护实例属性 - 外部可以访问但不推荐  
        self._age = age  
  
        # 私有实例属性 - 外部无法直接访问  
        self.__salary = salary  
        self.__bank_account = "1234567890"  # 私有属性  
        self.__internal_data = []  # 私有列表  
  
    # 🔥 公有方法 - 外部接口  
    def display_public_info(self):  
        """公有方法：显示公开信息"""  
        return f"姓名: {self.name}, 年龄: {self._age}"  
  
    # 🔥 受保护方法 - 内部使用，子类可用  
    def _calculate_bonus(self):  
        """受保护方法：计算奖金"""  
        return self.__salary * 0.1  
  
    # 🔥 私有方法 - 只能在类内部使用  
    def __process_sensitive_data(self):  
        """私有方法：处理敏感数据"""  
        return f"账户: {self.__bank_account[-4:]}"  
  
    # 🔥 属性装饰器 - 提供受控访问  
    @property  
    def salary(self):  
        """只读属性：获取薪水（带权限控制）"""  
        return f"薪资: {self.__salary}元"  
  
    @property  
    def age(self):  
        """获取年龄"""  
        return self._age  
  
    @age.setter  
    def age(self, value):  
        """设置年龄（带验证）"""  
        if 0 <= value <= 150:  
            self._age = value  
        else:  
            raise ValueError("年龄必须在0-150之间")  
  
    # 提供访问私有属性的公有方法  
    def get_salary_info(self):  
        """获取薪水信息（公有接口）"""  
        bonus = self._calculate_bonus()  # 调用受保护方法  
        total = self.__salary + bonus  
        return {  
            "基本工资": self.__salary,  
            "奖金": bonus,  
            "总额": total,  
            "账户尾号": self.__process_sensitive_data()  # 调用私有方法  
        }  
  
    def add_internal_record(self, record):  
        """添加内部记录（数据验证和封装）"""  
        if isinstance(record, str) and record.strip():  
            self.__internal_data.append(record)  
        else:  
            raise ValueError("无效记录")  
  
    def get_internal_records(self):  
        """获取内部记录（返回副本保护数据）"""  
        return self.__internal_data.copy()  
  
  
class Employee(Person):  
    """子类测试权限继承"""  
  
    def __init__(self, name, age, salary, department):  
        super().__init__(name, age, salary)  
        self.department = department  # 公有属性  
        self.__employee_id = "EMP001"  # 子类私有属性  
  
    def test_permissions(self):  
        """测试子类中的权限访问"""  
        print("\n" + "=" * 60)  
        print("子类权限测试")  
        print("=" * 60)  
  
        # 🔥 继承的公有属性  
        print(f"1. 继承的公有属性 name: {self.name}")  # ✅  
  
        # 🔥 继承的受保护属性  
        print(f"2. 继承的受保护属性 _age: {self._age}")  # ✅ 子类可以访问  
  
        # 🔥 继承的私有属性（需要特别注意）  
        try:  
            print(f"3. 继承的私有属性 __salary: {self.__salary}")  # ❌  
        except AttributeError:  
            print("3. 无法直接访问父类的私有属性 __salary")  
  
        # 父类私有属性在子类中的实际名称  
        print(f"4. 父类私有属性改名: {self._Person__salary}")  # ⚠️ 可以但不推荐  
  
        # 🔥 方法访问测试  
        print(f"5. 继承的公有方法: {self.display_public_info()}")  # ✅  
        print(f"6. 继承的受保护方法奖金: {self._calculate_bonus()}")  # ✅ 子类可以访问  
  
        try:  
            print(f"7. 继承的私有方法: {self.__process_sensitive_data()}")  # ❌  
        except AttributeError:  
            print("7. 无法调用父类的私有方法")  
  
        # 🔥 子类自己的私有属性  
        print(f"8. 子类私有属性访问测试:")  
        try:  
            print(self.__employee_id)  # ❌ 在父类方法中无法访问  
        except AttributeError:  
            print("   子类私有属性在父类方法中无法访问")  
        print(f"   实际名称: {self._Employee__employee_id}")  # ⚠️  
  
  
if __name__ == "__main__":  
    # 创建实例  
    person = Person("张三", 30, 15000)  
  
    print("=" * 60)  
    print("权限测试演示")  
    print("=" * 60)  
  
    # 🔥 1. 公有属性访问测试  
    print("\n1. 公有属性访问:")  
    print(f"直接访问 name: {person.name}")  # ✅  
    person.name = "李四"  # ✅ 可以直接修改  
    print(f"修改后 name: {person.name}")  
  
    # 🔥 2. 受保护属性访问测试  
    print("\n2. 受保护属性访问:")  
    print(f"访问 _age: {person._age}")  # ⚠️ 可以访问但不推荐  
    person._age = 35  # ⚠️ 可以修改但不推荐  
    print(f"修改后 _age: {person._age}")  
  
    # 🔥 3. 私有属性访问测试  
    print("\n3. 私有属性访问测试:")  
    try:  
        print(person.__salary)  # ❌ 直接访问失败  
    except AttributeError as e:  
        print(f"错误: {e}")  
  
    try:  
        print(person.__bank_account)  # ❌ 直接访问失败  
    except AttributeError as e:  
        print(f"错误: {e}")  
  
    # 🔥 4. 名称改写（Name Mangling）揭秘  
    print("\n4. 名称改写（Name Mangling）:")  
    print("Python内部将私有属性改名为: _类名__属性名")  
    print(f"访问 _Person__salary: {person._Person__salary}")  # ⚠️ 可以但不推荐  
    print(f"访问 _Person__bank_account: {person._Person__bank_account}")  
  
    # 🔥 5. 方法权限测试  
    print("\n5. 方法权限测试:")  
    print(f"调用公有方法: {person.display_public_info()}")  # ✅  
  
    try:  
        print(person.__process_sensitive_data())  # ❌ 私有方法无法直接调用  
    except AttributeError as e:  
        print(f"私有方法调用失败: {e}")  
  
    # 🔥 6. 使用属性装饰器访问  
    print("\n6. 属性装饰器访问:")  
    print(f"使用@property访问: {person.salary}")  # ✅ 只读  
    print(f"使用@property访问age: {person.age}")  # ✅  
    person.age = 40  # ✅ 通过setter修改  
    print(f"修改后age: {person.age}")  
  
    # 🔥 7. 通过公有接口访问私有数据  
    print("\n7. 通过公有接口访问私有数据:")  
    salary_info = person.get_salary_info()  
    print(f"薪水信息: {salary_info}")  
  
    # 🔥 8. 类属性权限测试  
    print("\n8. 类属性权限测试:")  
    print(f"公有类属性: {Person.public_class_attr}")  # ✅  
    print(f"受保护类属性: {Person._protected_class_attr}")  # ⚠️  
    try:  
        print(Person.__private_class_attr)  # ❌  
    except AttributeError:  
        print("私有类属性无法直接访问")  
    print(f"私有类属性改名后: {Person._Person__private_class_attr}")  # ⚠️  
  
    # 测试继承  
    print("\n" + "=" * 60)  
    print("继承中的权限测试")  
    print("=" * 60)  
    emp = Employee("王五", 28, 20000, "技术部")  
    emp.test_permissions()
```

## 多态的概念
### 概念与优点

- 不同的子类对象调用相同的方法，产生不同的执行结果。增加代码的灵活性
- **统一的接口，不同的实现**：比如测试数据生成器，可以有 `ExcelDataProvider`、`YamlDataProvider`、`DBDataProvider`，都实现 `get_data()` 方法，测试用例无需关心数据来源。
### 示例代码
```
class DataProvider:
    def get_data(self):
        raise NotImplementedError

class ExcelProvider(DataProvider):
    def get_data(self):
        return ["从Excel读取的数据"]

class YamlProvider(DataProvider):
    def get_data(self):
        return ["从YAML读取的数据"]

def run_tests(provider):
    data = provider.get_data()
    for item in data:
        print(f"执行测试: {item}")

run_tests(ExcelProvider())
run_tests(YamlProvider())
```

## 鸭子类型（Duck Typing）
### 概念说明
- Python 的多态不要求继承，只要对象有相应的方法即可调用，这就是"鸭子类型"。
### 示例代码
```
class Dog:
    def play(self):
        print("小狗在玩")

class Cat:
    def play(self):
        print("小猫在玩")

def play_with_animal(animal):
    animal.play()

play_with_animal(Dog())  # 输出：小狗在玩
play_with_animal(Cat())  # 输出：小猫在玩
```
